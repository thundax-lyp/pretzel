# 麻将消消玩法与产品需求

玩家从层叠牌山取牌，将牌放入六格收牌槽。同花色的三张连续数字组成顺子，三张相同牌组成刻子。玩家要同时判断上层牌压住了什么，以及槽内已有的牌能接成哪一组。牌山和收牌槽都清空时清台。

## 交付范围

以下描述首版目标。当前工程已实现随机牌山、取牌、自动成组和局内道具，并接入新版牌面与音频。固定教学、本机教学记录和结算页仍属于目标范围。

首版提供固定教学和随机牌山挑战。玩家可以单人离线开局、使用局内道具、查看结算和重玩。本机记录教学是否完成，微信小游戏与 Creator 预览使用相同玩法。联网排行、社交分享、广告奖励、付费道具和云存档均在首版范围之外。

## 流程与关卡

### 首次进入与重玩

- 本机首次进入时开始教学。教学完成后显示「开始挑战」。后续启动直达挑战，可从局内菜单重练教学。
- 进入挑战时发一副新牌。局内选择「重新发牌」时弹出确认，「继续」保留本局，「重新发牌」发新牌并重置槽位、统计、道具次数和撤回记录。
- 结算页的「重试本局」恢复原始牌面与牌位，重置本局状态。「下一局」发一副新牌。
- 微信切后台时保留当前进程中的牌局，回到前台可继续。应用重启后根据本机教学记录决定首屏，开启新局。

### 教学关

教学用固定的 12 张牌和六格收牌槽，演示遮挡、顺子和刻子。

| 阶段       | 初始牌位或触发条件                                                                                      | 操作与反馈                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 取牌与顺子 | 上层三张为 1 万、2 万、3 万，分别正压下层同列的三张 5 筒。下层另两行分别放 3 条、4 条、5 条与三张发财。 | 引导点上层三张，突出刚露出的下层牌。三张万字入槽后按顺子消除。 |
| 刻子       | 上层清空，三张 5 筒可取。                                                                               | 引导点三张 5 筒，显示「刻子」。                                |
| 自由清台   | 余下 3 条、4 条、5 条与三张发财。                                                                       | 解除选牌引导，玩家可任意顺序清空余牌。                         |
| 教学结算   | 牌山和槽均为空。                                                                                        | 记录本机教学完成，显示「教学完成」和「开始挑战」。             |

引导阶段只接受当前引导组内的可取牌。教学关提供「重新教学」，局内道具从正式挑战开始使用。

### 正式挑战

- 每局 240 张，牌山最高 9 层。各层张数按牌局布局配置。牌山逐层错位，所有牌明面朝上。
- 每局由 80 个三张组合组牌，覆盖全部 42 种牌面。万、筒、条各有「1–2–3」「2–3–4」「4–5–6」「7–8–9」各 4 组顺子，另有 6 组万刻子、6 组筒刻子和 5 组条刻子。每组数字刻子的点数从 1、5、6、7、8、9 中选择。东南西北、中发白、梅兰竹菊、春夏秋冬各有 1 组同名刻子。
- 新牌局必须有至少一条合法清台顺序。按实际遮挡、六格容量和自动成组优先级复放，该顺序须在零道具条件下清台。验证未通过的牌局重新生成。
- 复玩变化来自开局牌面分布与取牌顺序。所有挑战共用一套取牌、消除和结束规则。每局无倒计时。

## 取牌与遮挡

- 上层牌与下层牌的牌面投影有正面积重叠时，下层牌受压。仅接边或接角不算遮挡。同层牌之间不建立遮挡关系。
- 受压牌显示为不可取，点击仅提示「这张牌被压住了」。取走上层牌后更新遮挡，完全露出的牌在本次动作结算后可取。
- 按玩家点到的可见牌面与前后层级确定目标。点中受压牌时，点击不会转给另一张牌。
- 可取牌从左到右追加到收牌槽末尾。消除后其他牌按原入槽顺序左靠。自动消除只在收牌槽内发生，槽内牌不可手动重排。

## 自动消除与清台判定

| 组合 | 成立条件                                                          | 示例             |
| ---- | ----------------------------------------------------------------- | ---------------- |
| 顺子 | 万、筒或条中的同一花色，三张点数连续。槽位和入槽顺序不影响成立。  | 3 筒、1 筒、2 筒 |
| 刻子 | 三张相同牌。字牌、花牌和季节牌只参与同名刻子。                    | 7 条、7 条、7 条 |
| 散牌 | 混花色、跳号、从 9 跨到 1、数字两同一异、字牌、花牌、季节牌混组。 | 8 万、9 万、1 万 |

1. 入槽后从任意槽位中寻找三张合法组合。
2. 有多个候选时，将每组的三个槽位序号从小到大排列，逐位比较，选序号最靠前的一组。顺子和刻子使用同一优先级。例如槽内从左到右是 1 万、3 万、4 万、2 万时，槽位 1、2、4 组成的顺子优先于槽位 2、3、4。
3. 消除后重新检查槽内余牌，直到没有合法组合。显示「顺子」或「刻子」反馈。
4. 自动消除全部完成后判断牌局状态。第六张牌能成组时先消除，再判断槽是否已满。

### 剩余牌面无解时刷新

牌山剩余 48 张时开始检查，槽内牌不计入该阈值。进入该范围的取牌结算及后续每次消除结算后，按牌面数量检查牌山与槽内的剩余牌是否还能完整拆成顺子或刻子。无法拆分且存在可验证的修复方案时，自动重新生成牌山牌面，保留牌位、张数和槽内牌及顺序，不扣洗牌次数。按实际遮挡、槽容量和自动成组规则，新牌山必须有一条清台顺序。上一次取牌仍可撤回，撤回同时恢复到上一次取牌前的状态，包括撤销该次取牌触发的刷新。满槽、牌山为空或无法在现有张数内补齐槽牌时，保留现有恢复操作。

### 牌局状态

| 状态     | 触发条件                                             | 可执行操作                                                   |
| -------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| 进行中   | 牌山仍有牌，槽内少于六张，动作已经结算。             | 取可取牌、使用符合条件的道具、打开局内菜单。                 |
| 待恢复   | 槽满，或牌山取空后槽内有散牌，且消除或撤回仍可用。   | 显示具体阻塞原因，暂停取牌，开放可用的消除、撤回与局内菜单。 |
| 清台成功 | 牌山和收牌槽均为零。                                 | 查看结算，重试本局或进入下一局。                             |
| 挑战失败 | 槽满，或牌山取空后槽内有散牌，且消除和撤回均不可用。 | 查看结算，重试本局或进入下一局。                             |

牌飞入、自动消除或槽位重新排列期间锁定后续取牌、道具和重新发牌。先完成当前动作，再更新状态和可用操作。受压、不可用或被锁定的操作不改变牌局或道具次数。

## 局内道具

正式挑战每局免费获得固定次数。道具成功改变牌局后扣减次数。新局和重试本局均恢复次数。

| 道具 | 每局次数 | 可用条件                                                 | 生效结果                                                                                         |
| ---- | -------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 洗牌 | 2        | 牌山至少有两张，至少有两种牌面，且槽位未满。             | 重新分配牌山上的余牌。保留牌面数量、牌位、层数和槽内牌。清空撤回记录。                           |
| 消除 | 1        | 槽内至少一张牌，且当前未清台或失败。                     | 移除最早入槽的最多三张牌，余牌按顺序左靠。清空撤回记录，重新判定牌局状态。                       |
| 撤回 | 3        | 有上一次合法取牌记录，且该取牌后未使用洗牌、消除或撤回。 | 恢复取牌前的牌山、收牌槽、遮挡和统计，包含还原该次取牌触发的全部自动消除。扣一次撤回并清空记录。 |

- 洗牌若抽到相同排列需重抽。开局可解承诺适用于新发牌与重试本局。局内洗牌后，牌局仍按当前余牌和道具次数继续。
- 道具消除的牌不计入顺子或刻子数量。用道具消除最后的散牌后，牌山和槽都为空时同样清台。
- 每次合法取牌只记录其前一状态。撤回后，已消耗的其他道具次数保持原值。
- 道具始终显示剩余次数。次数用尽或不满足可用条件时置灰。

## 界面与结算

- 竖屏牌桌从上到下显示关卡或模式、六格收牌槽、剩余牌数、牌山、状态提示和道具。用亮暗与层叠边缘同时表达可取性。
- 状态区优先说明阻塞原因，例如「收牌槽满了」或「槽里还有散牌」。有恢复手段时同时点明可用道具。
- 胜利标题为「清台成功」，失败标题为「挑战结束」。结算显示顺子数、刻子数、道具清掉的牌数及剩余牌数。剩余牌数为牌山和槽内的牌数之和，统计随撤回更新。
- 关键操作保持在可触达区域。切回前台或调整屏幕尺寸后，牌面、卡槽和操作状态仍与实际牌局一致。

## 验收条件

| 场景       | 通过条件                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 教学       | 依次完成一次顺子和一次刻子引导。清空 12 张后可进入挑战。再次启动直达挑战，仍可重练。                                                       |
| 发牌与重玩 | 正式局满足 240 张、最高 9 层及 80 个三张组合，且每局包含全部 42 种牌面。参考顺序零道具清台。「重试本局」恢复原始牌局，「下一局」重新发牌。 |
| 遮挡       | 上层覆盖一角的下层牌不可取，仅接边的牌可取。最后一张压牌移开后，下层牌转为可取。                                                           |
| 顺子与刻子 | 乱序且跨槽位的同花色顺子与同名刻子可以消除。混花色、跳号、环绕组合和不同名的字牌、花牌或季节牌保持散牌。                                   |
| 多组候选   | 重叠组合按槽位序号选取，同样的槽状态得出同样结果。                                                                                         |
| 最后一格   | 第六张成组时先消除再继续，为散牌时按恢复能力进入待恢复或失败。                                                                             |
| 牌山取空   | 槽有散牌且可恢复时仍可使用对应道具。消除最后散牌后成功，恢复能力用尽时失败。                                                               |
| 道具       | 洗牌保留牌位、槽内顺序和牌面数量。消除按最早入槽移除。撤回能跨越自动消除还原现场，无效操作不扣次数。                                       |
| 连点与重开 | 动画中连点不会多进槽，上一局的动画回调不改变新牌局。                                                                                       |
| 结算统计   | 道具消除不增加顺子或刻子计数。撤回恢复对应组数、槽状态和牌山状态。                                                                         |
