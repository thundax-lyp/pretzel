# Flip Zoo 第二关难度校准报告

## 范围与证据

本报告记录当前冻结的 40 副微信第二关牌局的离线校准结果。每副 240 张牌、80 组三消，十类沙漏几何各含 A/B/C/D 四个变种；A/B/C/D 是牌库变种，与翻牌策略组别无关。验收目标与布局约束由 `FLIP-ZOO-LAYOUT-GUIDE.md` 定义。

- 机器可读证据：`miniprograms/flip-zoo/test/fixed-board-calibration.json`。
- 证据文件 SHA-256：`48ca3da2f2b8eccda6e4eaaa81a2351b725c2e84f2d5c85855a99d4498b3216d`。
- 每副配置指纹为对应记录的 `boardHash`，由 `{ layout, kinds, bindings }` 的 JSON 内容计算 SHA-256；逐层结构、绑定位置、单牌数量与种类数保留在 `structure` 中。
- `test/board-calibration.test.mjs` 将证据与当前牌库逐副比对，并检查双指标、样本量及整库加权汇总。

配置指纹只覆盖布局、牌面和绑定，不覆盖规则与选牌策略实现；配置、取牌规则或策略变化后均须重新校准。当前文件保持一套冻结牌库的结果，不累积候选筛选或排错历史。

## 运行条件

| 项目       | 本报告口径                                                       |

| 选牌策略   | `visible-lookahead`，玩家可见信息                                |
| 卡槽       | 全程 6 格，不解锁第 7 格                                         |
| 道具与复活 | 均不使用                                                         |
| 误选率     | `errorRate = 0`                                                  |
| 复核样本   | 每副至少 512 局，距离任一验收边界不超过 2 个百分点时至少 1024 局 |

## 校验与复现

在 `miniprograms/flip-zoo/` 中校验证据与当前配置、结构和参考解的一致性：

```sh
node --test test/board-calibration.test.mjs test/board-api.test.mjs
```

按表中编号、局数及起始种子逐副复跑。例如第 1 副：

```sh
npm run --silent simulate:win-rate -- --source wechat --board 1 --rounds 1024 --seed 300000000 --error-rate 0 --json
```

完整复核须逐副采用本表参数，再合计 `rounds`、`reached30` 和 `wins`。默认对全部牌局使用同一起始种子的命令可用于统一预算对照，但不复现本报告的逐副结果。

## 证据边界

结构校验与六格参考解证明当前牌局满足约束且存在清盘路径；模拟比率反映指定可见牌策略、卡槽和误选率下的表现。源码与证据一致性检查不会重新执行全部 30,720 局。真人通关率、真人达到 30% 的比例、时长和退出进度，以及真机和线上环境行为未由本报告证明。
