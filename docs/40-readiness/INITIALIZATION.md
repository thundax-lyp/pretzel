# 初始化环境

## 工程状态

| 工程       | 配置与能力                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| 管理端     | React 18、TypeScript、Ant Design 6、Pro Components 3；登录、用户、角色、权限、菜单、部门、字典和系统日志 |
| 后端       | Java 21、Spring Boot、Maven 多模块与 DDD；common、biz、starter 分工；V1 初始化结构与显式管理员初始化     |
| 微信小程序 | TypeScript、微信 API 类型声明、严格类型检查；启动、首页、游戏三页骨架                                    |
| 基础环境   | 独立 smoke、release 配置，MySQL 8.4 与 Redis 7.2                                                         |
| 配置       | 公开 .env.example；.env、dev.env 与凭据目录不提交                                                        |
| 文档       | 需求、契约、设计、规范和验收独立维护，README 树形导航                                                    |

人工维护代码与配置使用 4 个空格缩进。Java 包使用 config、util、architecture；管理端当前用户与会话能力归属 session；游戏领域按 board、slot 组织。

## 质量检查

| CI 检查     | 验证范围                                                             |
| ----------- | -------------------------------------------------------------------- |
| admin       | 格式、结构 lint、Oxlint、结构检查回归测试、Vitest、TypeScript 与构建 |
| backend     | MySQL/Redis 服务、Spotless、Checkstyle、ArchUnit 和 Maven 全量测试   |
| miniprogram | 锁文件安装、严格类型检查、Oxlint、格式                               |
| tooling     | Ruff 静态检查与格式、Python 关卡设计规则测试、Shell 语法             |

CI 仅由面向 main 的 PR 触发，按 workflow 和 PR 编号隔离并发运行。同一 PR 的新运行会自动取消过期运行。GitHub Actions 使用只读仓库内容权限。

## 验证结果

- 后端：112 个测试套件、403 项测试通过，包含领域架构、真实 MySQL 8.4/Redis 登录授权、撤权、刷新、退出、改密失效、联系方式加密及资料更新边界。
- 管理端：20 个测试文件、38 项测试及生产构建通过；真实浏览器验证登录、服务端菜单、用户抽屉、角色保存、主题和窄屏布局。
- 小程序：类型、lint、格式与 TypeScript 转译后的页面导航检查通过。
- 结构与评审工具：10 项回归测试通过；仓库格式、Oxlint、Ruff 与 Shell 语法检查通过。
- 离线关卡设计 Skill：62 项 Node 规则与集成测试通过，另有共享研究工具 24 项 Python 回归；生成、真实布局统一导入、预算控制、自动报告与独立回放可复现，不代表微信游戏已交付。
- 环境初始化：重复执行、私有权限与跨环境隔离检查通过。

## main 保护

目标策略：必须通过 PR，四项 CI 成功且分支更新到最新 main，讨论已解决；管理员同样遵守，禁止强推和删除。策略位于 .github/main-protection.json。

远端保护尚未启用：当前套餐不支持该私有仓库的分支保护，GitHub 返回 HTTP 403。仓库保持 private；具备套餐能力后，通过配置脚本应用策略并回读确认。策略文件本身不会自动启用保护。

## 未覆盖范围

完整游戏、广告分享、动物收集和榜单尚未实现；微信开发者工具预览、真机及生产发布未验收。当前配置提供基础设施，不包含整套应用镜像发布流程。Pro Components 使用固定测试版；加载性能尚未验收。
