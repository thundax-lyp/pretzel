# 麻将消消音频设计

## 当前使用的音效

路径相对于麻将消消工程的 `assets/resources/audio/`。

| 文件               | 音色设计                   | 触发时机                                                 |
| ------------------ | -------------------------- | -------------------------------------------------------- |
| `button-click.mp3` | 短促、柔和的轻敲声。       | 重新发牌、撤回，或洗牌和消除无法执行并显示提示时播放。   |
| `tile-select.mp3`  | 短促的木质牌碰声。         | 合法取牌并开始飞入收牌槽时播放。                         |
| `tile-match.mp3`   | 双击牌声和上行拨弦。       | 自动成组或使用消除道具后播放。最后一组清台时播放清台音。 |
| `tile-shuffle.mp3` | 擦动声和渐密的牌碰声。     | 洗牌操作生效后播放。                                     |
| `round-clear.mp3`  | 上行拨弦乐句，以和弦收束。 | 牌山和收牌槽同时清空时播放。                             |

这些音效为项目原创合成，使用振荡器、生成噪声和包络从零制作，未使用外部采样。音频加载与牌桌初始化并行。

## 当前使用的背景音乐

`assets/resources/audio/table-music.mp3` 为约 33 秒的原创循环配乐《喜上牌桌》，采用 116 BPM 的二拍律动。合成笛声演奏五声音阶旋律，拨弦铺底，鼓、木鱼和小锣在乐句间点缀。参考节庆吹打乐的节拍和配器，旋律与音色均为原创合成。首次触摸或点击后以独立音轨循环播放，默认音量 24%。切到后台暂停，回到前台续播。
