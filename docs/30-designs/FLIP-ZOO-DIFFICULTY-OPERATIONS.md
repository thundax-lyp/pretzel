# Flip Zoo 提高难度的操作与效果评分

## 评分口径

评分表示操作提高难度的预期作用强度，来自本轮布局调整、规则检查与离线模拟经验，不是精确的通关率换算，也不是玩家难度等级。同一操作在不同配牌上的效果会变化，多项操作的分数不能相加。

| 分数 | 作用强度 | 使用方式                                       |
| ---- | -------- | ---------------------------------------------- |
| 1    | 很弱     | 用于微调，通常不适合单独承担加难目标。         |
| 2    | 较弱     | 作为辅助调整，与配牌或遮挡操作结合。           |
| 3    | 中等     | 能改变局部压力，需要检查具体取牌顺序。         |
| 4    | 较强     | 优先使用的加难手段，通常需要同步验证参考解。   |
| 5    | 很强     | 容易显著改变难度，少量使用并重点检查前段失败。 |

下表以六格、无道具、无复活、玩家视角策略为主要参照。具体布局约束与验收目标由 `FLIP-ZOO-LAYOUT-GUIDE.md` 维护，逐副模拟结果保存在 `FLIP-ZOO-DESIGN.md` 的“当前布局复核”部分。

## 操作与效果

| 操作                                                     | 效果评分 | 为什么可能变难                                                 | 适用条件与注意点                                                                     |
| -------------------------------------------------------- | -------: | -------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 从密集层抽牌上移，形成中部收窄、顶部展开的沙漏结构       |        3 | 减少单层集中摆牌，为多层清障和交叉遮挡创造空间。               | 层数增加本身不保证更难；顶部展开过大，也可能增加可取牌和三消机会。                   |
| 相邻层半格错位，减少连续“1 盖 1”，形成“2～4 盖 1”        |        4 | 取到下层目标牌前，需要先处理多张上层牌。                       | 上层牌若能顺手三消，实际压力仍可能很低，应配合不同三消组布置。                       |
| 分散同款牌的露出时机，把补齐三消所需的牌放到清障路径之后 |        4 | 玩家更早持有一两张同款，却不能马上补齐第三张，槽位被持续占用。 | 按实际可达路径判断早晚，不能只看层号；同时保留可发现、可执行的解法。                 |
| 交错多个三消组，让玩家同时持有数个未完成组               |        5 | 多个组争用有限槽位，取错一张就可能失去等待第三张牌的空间。     | 最容易把牌局推成过早失败，需要控制同时等待的组数和等待时长。                         |
| 增加锁定牌组数                                           |        3 | 整对取牌需要两个空位，限制了卡槽紧张时的操作。                 | 效果不随组数单调增加；整对同款也可能帮助快速三消，不能只追求数量。                   |
| 把锁定牌安排在关键清障路径上，并延后其第三张同款的露出   |        4 | 玩家需要先腾出两个槽位，再承受等待同款补齐的压力。             | 比单纯加组数更有针对性；检查整对可取时机，防止形成无解阻塞。                         |
| 把清障与跨组占槽压力安排到前段实际可达路径中             |        4 | 提前制造取牌取舍，降低轻松越过前段的概率。                     | 用于前段偏易的牌局；前段已经偏难时，不再继续提前压力。                               |
| 把压力集中到中下层与收尾路径                             |        3 | 前段仍可推进，但后续补牌与腾槽更困难。                         | 用于前段合适、通关仍偏易的牌局；不能单独解决开局偏易。                               |
| 减少一个可用槽位                                         |        5 | 直接减少暂存未完成组的余地，会放大遮挡与锁定牌造成的压力。     | 属于规则级手段。本轮六格与七格对照支持其作用较强；当前分享解锁第七格的规则保持不变。 |

## 推荐使用顺序

1. **先整理几何。** 通过沙漏分层与半格错位减少连续直叠，检查同层不重叠和逐层承托。
2. **重点调整配牌依赖。** 让清障涉及不同三消组，让第三张同款的露出需要取舍。这是主要加难手段。
3. **用锁定牌补压力。** 优先选择关键位置，再考虑增加组数，避免无目的堆量。
4. **按失败阶段调整。** 前段偏易时，把压力移到前段可达路径；前段已合适时，再增加后段压力。
5. **局部调整无效时重建配牌。** 保留合格几何，重新安排三消组与参考取牌路径，再验证难度；重建本身不保证加难。

每次优先调整一类因素，再检查参考解和模拟结果。评分用于选择操作，不代替六格可解性检查，也不代替真实试玩。

## 判断操作是否奏效

- 需要清障的牌变多，但清障过程可以连续三消：结构更复杂，卡槽压力未必提高。
- 同时等待补齐的三消组变多，且仍有合理腾槽路线：通常是有效的加难方向。
- 开局就只能盲选、频繁满槽，或参考解不能清盘：应回调，不能把失败率更高直接当作更好的难度。
- 六格结果合适，但解锁第七格后明显变易：分别记录两种条件，不能混合判断。
