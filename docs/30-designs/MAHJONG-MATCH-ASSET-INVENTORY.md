# 麻将消消素材清单

## 当前使用的图片

路径相对于麻将消消工程的 `assets/resources/art/`。运行时资源文件采用小写 kebab-case，与 Flip Zoo 的资源命名一致。

| 文件                                                              | 数量 | 用途                                                       |
| ----------------------------------------------------------------- | ---: | ---------------------------------------------------------- |
| `table.png`                                                       |    1 | 牌桌背景。                                                 |
| `tools.png`                                                       |    1 | 牌桌金色美术字，以及洗牌、消除、撤回的图标和图片文字按钮。 |
| `tiles/character-1.png` 至 `character-9.png`                      |    9 | 万字牌，可组成顺子与同名刻子。                             |
| `tiles/dot-1.png` 至 `dot-9.png`                                  |    9 | 筒字牌，可组成顺子与同名刻子。                             |
| `tiles/bamboo-1.png` 至 `bamboo-9.png`                            |    9 | 条字牌，可组成顺子与同名刻子。                             |
| `tiles/wind-*.png`、`red.png`、`green.png`、`white.png`           |    7 | 东、南、西、北、中、发、白，各自组成同名刻子。             |
| `tiles/plum.png`、`orchid.png`、`bamboo.png`、`chrysanthemum.png` |    4 | 梅、兰、竹、菊，各自组成同名刻子。                         |
| `tiles/spring.png`、`summer.png`、`autumn.png`、`winter.png`      |    4 | 春、夏、秋、冬，各自组成同名刻子。                         |

42 种正面均为 120 × 166 像素的透明 PNG，由牌山和收牌槽共用。牌面在统一的白瓷底模上叠加独立绘制的图案。牌身有釉面高光、圆角倒角及浅雾蓝下缘。一条使用带有翼羽、眼神光和竹枝的翠鸟图案。筒牌使用放大的双环釉纹，一筒以八瓣花心区分。万字、字牌及花季牌的汉字用行楷，万字牌的点数为蓝墨、「萬」字为朱砂色。

`tile-back.png` 使用同样的画布，背面为浅蓝釉面和淡压边，下缘为暖白色，可用于教学翻牌。当前正式对局的牌山按需求明面朝上。

## 制作来源

新版牌身、牌背及图案使用矢量几何图形和路径重新绘制，再导出 PNG。万字牌、字牌及花季牌的汉字在导出时由浏览器渲染，字体候选依次为 `Xingkai TC`、`Kaiti TC`、`STKaiti`。
