## 立体牌面与动效定稿

牌面采用正视角的麻将牌质感，包含象牙色正面、高光边、下沿厚度、绿色底座与落地阴影。动物、眼睛和腿数共用一致的版式，棋盘、卡槽和暂存区使用同一种牌面。遮挡牌降低亮度，可取牌保持明亮，移出选牌使用金色边框及勾选标记。

游戏页按可见安全区分配题目、棋盘、暂存区、七格卡槽与道具栏。空暂存区收起为一行说明，为棋盘提供更大的可用面积；有暂存牌时展开滚动区。分离牌堆可在屏幕内横排或竖排，选择能容纳更大牌面的排列。各牌堆内部的相对坐标与遮挡关系保持一致。首次第一关第一题显示整槽同时满足眼睛数和腿数的文字引导。

| 场景       | 表现与时长                                              | 交互与数据约束                                                            |
| ---------- | ------------------------------------------------------- | ------------------------------------------------------------------------- |
| 关卡开始   | 牌从左上方依层序码入棋盘，逐张间隔 12ms，单张移动 360ms | 首次进入本关播放，约 1 秒内完成，码牌期间暂停取牌；同步同一关保持牌堆稳定 |
| 点击按钮   | 按下缩至 96%，松开恢复，70—100ms                        | 取消触摸恢复原状；滚动手势不触发按钮                                      |
| 取牌入槽   | 牌飞向目标卡槽，280ms，到位轻弹 220ms                   | 操作确认后播放，目标槽位在飞行期间隐藏重复牌面                            |
| 达成题目   | 槽内牌抬升并缩小消失，330ms，星点散开并显示消除提示     | 按已确认的新题目推进，动画不参与消除和满槽判定                            |
| 第一关完成 | 熊猫弹层轻弹，散开彩屑，出现进入第二关按钮              | 第二关通过原入口进入                                                      |
| 最终通关   | 快乐熊猫、彩屑与真实解锁数量                            | 待结算状态只展示确认中，收到确认结果后播放庆祝                            |
| 闯关失败   | 失败熊猫、面板短促晃动与失败原因                        | 卡槽牌保留，重新挑战从第一关开始                                          |
| 移出       | 槽内选牌金边勾选，确认后飞入暂存区，280ms               | 选中 1—3 张，服务端确认后减少库存，取消不消耗                             |
| 暂存放回   | 沿用同一牌面，从暂存区飞回棋盘原位，300ms               | 底牌全部归位后可免费复位，保持卡槽、进度和库存                            |
| 纠错       | 修正后的牌面短暂倾转并归位，显示生效提示                | 仅在操作确认后播放，以返回快照保留题目进度                                |
| 重排       | 返回快照重新码牌，显示生效提示                          | 有效方案确认后播放，无方案或请求失败保留现有画面与库存事实                |
| 被遮挡的牌 | 牌身短促晃动，220ms                                     | 不推进对局，不弹出阻塞说明框                                              |

短说明弹层按内容缩短高度。榜单使用中文范围标题，周期切换位于标题下方。图鉴按动物立绘网格展示。预览数据包含已解锁动物、示例榜单和通关动物种类，用于本地视觉走查，真实平台奖励另行联调。

复位牌保留取牌锚点与底牌信息，受阻时灰显并显示“等待底牌”，点击可查看原因。复位成功后在棋盘正确层序中移动到原位，避免飞行牌穿到上层牌前。三种道具使用“移出／纠错／重排”，纠错提供跨题组合修复，重排保护复位锚点。
