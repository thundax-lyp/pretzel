# 休闲消除类游戏 UI 与 UE 设计原则

适用于以辨认、选择、匹配、消除为核心，并结合关卡挑战、道具或收集反馈的休闲游戏。界面需要帮助玩家理解局面、顺畅操作，并从变化与成果中获得愉悦。

设计要同时处理整体吸引力、玩法信息、操作控制与情绪节奏。清楚不等于好看，装饰丰富不等于精致，操作顺畅也不能单独证明游戏有趣。各方面分别判断，再在完整体验中协调。

## 适用范围与类型取舍

| 游玩或观看情境               | 视觉与体验重点                             | 需要控制的倾向                             |
| ---------------------------- | ------------------------------------------ | ------------------------------------------ |
| 观察与规划型消除、叠牌或配对 | 稳定局面、清楚层次、便于比较的属性与关系   | 持续晃动、强提示和频繁遮挡打断思考         |
| 连锁与快速反应型消除         | 明显变化、连续空间关系、轻快操作和反馈     | 演出堆积掩盖下一步操作，所有事件同样强烈   |
| 收集与养成结合的休闲游戏     | 角色个性、成果展示、亲和氛围和长期视觉记忆 | 入口、角标和领奖提示挤压收集对象           |
| 关卡选择与进度浏览           | 可理解的进度、下一步目标、清楚的解锁条件   | 路线装饰掩盖实际入口，锁定状态没有原因     |
| 设置、说明、背包等辅助情境   | 与游戏协调的风格、有效组织、快速返回       | 装饰和过渡拖慢重复使用，辅助功能抢走主角   |
| 宣传图、展示片与传播片段     | 主题识别、代表性瞬间和吸引力               | 将面向观看的夸张表现直接变成持续游玩的常态 |

同一游戏可以包含多种情境，按当前活动调整信息密度与表现强度。类型不限定唯一美术风格；扁平、手绘、立体、复古和材质化表现都可以成立。目标玩家的阅读与操作习惯、设备、观看距离和游玩环境共同影响设计取舍。

原则编号用于定位设计意图，检测点按同一编号派生子项。例如 TXT-02 定义字号取舍，TXT-02.1 检查实际尺度下的阅读，TXT-02.2 检查同屏字号层级。原则说明为什么，检测点明确检查什么，独立编号的检测方法说明如何取证；一个检测点可以对应多个方法。具体项目的参数与实际审核结果另行记录。新增检测点沿用父原则编号，不按审核批次重新编号；已移除的编号不复用。

下文按设计领域组织原则。整体构图、内容辨识、主要操作及实际出现的状态属于基础覆盖；道具、排行榜、商业化、复杂手势等只在存在相应能力时适用，不要求所有游戏增加这些功能。

## 整体审美原则

1. **VIS-01** **主题与情绪清楚。** 整屏传达统一的世界、性格与情绪，让玩家感到亲和、轻快、宁静或兴奋。角色、场景、字体与操作表现共同建立身份，避免只靠标题说明游戏是什么。
2. **VIS-02** **构图具有重心。** 主体、关键信息和行动入口形成有主次的关系，视线能够自然移动。画面可以有多个兴趣点，但应避免同时争夺同一层级的注意。
3. **VIS-03** **比例与疏密有节奏。** 游戏对象、容器、文字和控件的体量协调。留白衬托主体、分隔层次并带来呼吸感；空白过多但主体过小，同样可能削弱完整感。
4. **VIS-04** **色彩与明暗组织画面。** 大色块维持整体气氛，小范围强调引导关注。高饱和、低饱和、亮色和暗色均需放在相互关系中判断，不能由单个色值或流行配色决定美感。
5. **VIS-05** **形体与材质彼此呼应。** 轮廓、线条、光照、阴影和质感形成有意的组合。二维与立体元素可以混用，但需要协调视觉重量、细节程度和空间关系。
6. **VIS-06** **简洁保留趣味与个性。** 去掉干扰时保留主题识别、角色魅力和有意义的细节。增加装饰不天然更精致，移除装饰也不天然更高级；规则面板不能代替所有场景表达。
7. **VIS-07** **细节支持完整感。** 对齐、裁切、接缝、图文比例、资源清晰度与状态变化相互协调。精细程度应与目标风格一致，不能局部写实、局部粗略而没有表达上的理由。
8. **VIS-08** **静态与动态形成统一体验。** 静止画面有清楚构图，运动过程有关注重点和节奏。不能只追求一张截图，也不能用持续运动掩盖静态构图的问题。

## 三条交互总原则

### 1 看得清 让玩法信息具有明确层级 **CORE-01**

玩家容易分辨当前目标、可操作对象、进展与限制。视觉重量与信息对当前决策的重要程度相符，必要信息尽量直接呈现，相同含义保持稳定表达。

界面减少意外的阅读与操作障碍，同时保留玩法有意设置的挑战。简化应减少无关干扰，不能以隐藏关键条件、属性或风险为代价。

### 2 点得准 让操作符合直觉与预期 **CORE-02**

对象外观帮助玩家判断是否可以操作，以及操作会产生什么效果。相似操作保持一致，重要入口容易发现，相邻操作容易区分。

布局适合实际输入方式与设备。控件在操作前后保持稳定，对误触、高代价操作和中断提供适当保护，让玩家感到过程可控。

### 3 反馈可信 让变化清楚并带来愉悦 **CORE-03**

每次操作都有可感知的回应，玩家能够理解什么发生了变化、为什么变化，以及接下来可以做什么。等待、成功、失败和不确定结果有清楚区别。

反馈强度与事件的重要性和发生频率相称。日常操作轻快，关键达成突出，奖励与庆祝有层次；反复游玩时仍然舒适，不用演出拖慢思考和操作。

## 构图 布局与空间原则

- **LAY-01** 先安排当前任务的主区域，再分配辅助信息和装饰；避免把剩余空间当作棋盘或主要对象的唯一预算。
- **LAY-02** 用位置、尺度、明暗与留白组织观看顺序。视觉焦点和操作焦点可以不同，但二者的关系应容易理解。
- **LAY-03** 相关内容靠近并形成分组，互不相关的内容保持足够区分。对齐与间距要表达归属，而不仅是整齐。
- **LAY-04** 采用一致的基础节奏，同时允许重点区域有意变化。机械等分、绝对对称或所有间距相同，不一定适合场景构图。
- **LAY-05** 兼顾视觉中心与几何中心，轮廓不对称或透明留白较多的素材需要按实际视觉体量安排位置。
- **LAY-06** 内容数量变化时保留稳定的阅读与操作关系；少量内容不显残缺，大量内容不拥挤，局部更新不推动正在操作的入口。
- **LAY-07** 固定区域与滚动区域各有清楚职责，内容不被固定控件盖住，滚动终点和下一步操作可到达。
- **LAY-08** 屏幕裁切、系统覆盖和不同观看比例不应切断主要关系。空间不足时先重排、简化辅助内容或提供有意的浏览方式。

## 色彩与明暗原则

- **COL-01** 配色先建立整体气氛，再分配内容、操作、状态与装饰的角色，避免每个对象独立选择醒目颜色。
- **COL-02** 主色、辅助色与强调色通过面积、位置、饱和度和明暗共同形成层级，不要求固定数量或固定面积比例。
- **COL-03** 同时判断颜色是否和谐、对象是否可辨、文字是否可读；这三个问题相关但不能相互替代。
- **COL-04** 颜色含义在同一游戏中保持稳定，危险、选择、奖励和不可用等表达避免相互冲突。不能假设某种颜色对所有玩家具有唯一含义。
- **COL-05** 关键属性和状态使用颜色之外的符号、形状、文字或位置辅助表达，避免仅凭细微色差判断。
- **COL-06** 将最终叠加效果作为判断对象，考虑纹理、透明度、高光、阴影及运动背景，不能只看孤立色板。
- **COL-07** 不可用和次要状态通过多种视觉手段降级，必要名称、原因和数值仍可辨认，避免整体变淡后信息消失。
- **COL-08** 同一颜色在不同背景和相邻色块下重新判断，跨页面的角色保持一致，但可以随场景调整明暗与浓淡。

## 形体 材质与风格一致性原则

- **FORM-01** 形体语言与游戏气质相符，轮廓、圆角、尖角、厚度和线条传达有意的性格，而不是任意混合。
- **FORM-02** 同类对象的描边、光照方向、阴影软硬和细节密度相互协调；主次差异服务身份与层级。
- **FORM-03** 材质帮助表达触感和主题，木纹、金属、高光或半透明效果不应遮盖文字与属性。
- **FORM-04** 深度线索说明层次，不能让非交互装饰比实际按钮更像可按物体，也不能让底板厚度掩盖遮挡关系。
- **FORM-05** 场景、游戏对象和功能面板可以采用不同表现强度，但需有共享的色调、轮廓或图形语言连接。
- **FORM-06** 保留素材原有比例与有效轮廓，避免局部拉伸、边框变厚、阴影方向错乱和透明边缘产生脏边。
- **FORM-07** 风格统一以完整效果判断，不要求所有素材使用同一种制作技术，也不因使用位图、矢量或三维就预先判定品质。

## 背景与场景装饰原则

- **BG-01** 背景建立主题、空间和情绪，同时为棋子、目标、文字与控件留下清楚的观看环境。
- **BG-02** 需要阅读、比较和精细操作的区域保持视觉安静，较丰富的装饰安排在不会干扰任务的位置。
- **BG-03** 场景层次、地面、阴影和对象站位相互支持，让对象像处在环境中，而不是无意悬浮或贴在背景上。
- **BG-04** 背景中的路径、边缘、亮点和透视线应有意引导视线，避免把注意力带向不可达或无意义的位置。
- **BG-05** 重复纹理、装饰密度和色彩变化控制节奏，不因填满空白而制造噪声，也不因减少细节而失去氛围。
- **BG-06** 不同屏幕裁切和内容状态下，主要构图仍然成立，重要视觉元素不依赖某一种截图比例才能完整呈现。
- **BG-07** 环境运动维持气氛，观察和阅读区域保持稳定。装饰循环不承担必须记住的信息，也不持续催促玩家。

## 游戏对象与收集内容原则

- **OBJ-01** 棋子、卡牌、角色和道具具有容易记住的外观，身份与功能信息相互配合，不能要求玩家仅凭现实常识猜规则属性。
- **OBJ-02** 不同对象通过轮廓、图案、形状、明暗等多种线索区分，缩小或聚集后仍然成立；精细装饰不能成为唯一识别依据。
- **OBJ-03** 同类对象在尺度、视觉基线和属性位置上保持秩序，个性差异不破坏比较与扫读。
- **OBJ-04** 属性、数量、状态和选择标记有清楚归属，不与相邻对象混淆，不能被角色肢体、阴影或徽标遮住。
- **OBJ-05** 叠放、邻接、分组、选中和受阻关系在组合画面中清楚呈现。独立素材好看，不能证明进入棋盘后仍好看、好用。
- **OBJ-06** 可操作与不可操作状态能被辨认，视觉表现与实际规则一致；局部露出不应无意暗示可以取用。
- **OBJ-07** 收集展示区分身份、拥有状态、数量和阶段变化，避免把解锁、获得、升级等不同含义混在同一个提示中。
- **OBJ-08** 稀有、首次获得、完成或其他特殊标记只表达实际存在的含义，不让所有对象都带同等强烈的装饰。
- **OBJ-09** 展示数量变化时协调站位、尺度与留白；分页、筛选或滚动服务内容可达性，不打断主体构图与返回位置。

## 字体与文字排版原则

- **TXT-01** 按文字职责选择字形表现。固定文本、较大展示尺寸且承担品牌或情绪职责的文字，优先采用定制美术字作为主视觉资产；固定主要行动适合有个性的展示字形，同时保持快速辨认和状态区别。数值、规则、状态与连续阅读采用稳定清楚的排版。字体和配色相容，只能说明基础协调，不能证明品牌表达充分。
- **TXT-02** 字号依据观看尺度、对象职责与相邻信息确定；标题、正文、辅助信息和关键数值形成层级，不能只按可用空间不断缩小。
- **TXT-03** 字重、字宽、描边、阴影与发光共同决定视觉重量。装饰应强化表达，不能堵住字腔、模糊笔画或让所有文字同样沉重。
- **TXT-04** 字距、行距、行长、换行与留白适合阅读内容；长正文通常需要连续阅读秩序，短标签和数值需要明确对齐关系。
- **TXT-05** 字色与背景既要协调，也要易读；判断最终显示区域的明暗关系，而不是仅检查单一静态背景。
- **TXT-06** 文字与图标、单位、数值的顺序和基线稳定；相同概念保持相同称呼，数量与所属对象相邻。
- **TXT-07** 重要数值、成本和规则条件不能因省略失去含义。长名称与说明有合适的完整查看方式，摘要与精确值保持一致。
- **TXT-08** 不同语言、字符、长数字和特殊符号有合理空间，字体替代或字形缺失不应让关键内容变空白或改变归属。
- **TXT-09** 文字的美术表达与承载技术分别选择。定制美术字可采用矢量、字体或图像等适合的载体，可变内容与连续阅读保持灵活；最终尺度、字形、替代与状态仍需验证，不把美术字限定为位图。
- **TXT-10** 描述动作与结果时使用玩家能理解的语言，成功、失败、取消和等待的表述有明确区别，不把内部技术状态直接当作面向玩家的说明。
- **TXT-11** 展示文字自身具备与职责相称的美术完成度。品牌名与情绪标题分别检查字形个性、整体轮廓、字间节奏、厚度、材质、光影、趣味细节与品牌记忆，并与角色、场景的精细程度协调。扁平表达也可通过独特轮廓和节奏成立，不强制增加所有效果；角色已有个性不能代替标题自身的表达。当前静态关系已足以显示表达偏弱时，应提出具体审美调整；实际尺度、动态及输入的缺口分别保留。

## 图标 标记与信息图形原则

- **ICO-01** 图标表达真实用途，外形隐喻与操作含义一致；不熟悉或容易歧义的图标辅以文字或上下文。
- **ICO-02** 同一层级的图标在轮廓、线条、填充、透视和材质上协调，按视觉体量对齐，不能只追求外接矩形相同。
- **ICO-03** 图标、文字与数量组成完整信息，避免过大的图标挤压名称，或微小图标变成无法辨认的色点。
- **ICO-04** 角标、勾选、锁定、警告和进度标记各有稳定含义，位置不遮挡主体和其他重要信息。
- **ICO-05** 标记的出现、消失与数量变化要反映实际状态，未读、可领取和新内容不能混用同一种无解释提示。
- **ICO-06** 进度、计量和比较图形有清楚方向、范围及单位，装饰形状不能暗示不存在的容量或剩余机会。
- **ICO-07** 提示强度与重要程度相称，避免每个入口都使用红点、闪烁或奖励光效而失去区分能力。

## 按钮 手势与操作控件原则

- **ACT-01** 当前任务的首要行动容易发现，辅助与低频操作有适当层级；高代价操作清楚但不诱导误触。
- **ACT-02** 按钮形状、材质、图标和文案共同表达用途。装饰与操作控件可区分，外观相同的控件不承担无关行为。
- **ACT-03** 点击区、间距、位置和操作姿势适合目标输入方式；小图标可以有更大的操作范围，但相邻区域不能争抢输入。
- **ACT-04** 按压反馈及时且目标稳定，不因缩放、布局更新或状态文案改变操作归属。
- **ACT-05** 可用、按下、选中、不可用、锁定与处理中等适用状态容易区分，并说明相关原因或条件。
- **ACT-06** 点击、拖动、滑动与长按的区分清楚，避免浏览列表时误用道具，或操作完成后仍执行旧动作。拖动的来源、当前对象、落点与有效性清楚，手指或指针遮挡不应使关键判断失去依据。
- **ACT-07** 关键操作不依赖难以发现的手势；需要的替代入口与提示符合实际平台和玩家能力。实际支持键鼠或手柄时，焦点、导航顺序、确认与返回具有清楚且连续的关系。
- **ACT-08** 重复操作保持简短，保护措施与成本相称；确认、取消和可撤回行为遵循实际玩法，而非机械增加弹窗。
- **ACT-09** 操作前说明资源、时间或观看等成本，操作后说明真实结果；等待时不让连续触发造成含义不明的多次执行。

## 导航 列表与内容承托原则

- **NAV-01** 页面、区域与内容层级有可理解的关系，返回后尽量保留选择、页码、滚动与正在完成的任务。
- **NAV-02** 导航表达当前所在位置与可去方向，选中态清楚；入口数量和分组服从使用频率，不把全部能力同时堆在首屏。
- **NAV-03** 面板、底板、标签与边框按阅读、分组或操作需要使用，体量不压过内容，场景表达不必全部装进规则卡片。
- **NAV-04** 列表与网格为扫读和比较组织信息，名称、数值、状态与操作的对齐稳定，排序和切换含义清楚。
- **NAV-05** 长内容有可发现的浏览方式，首末项与固定操作均可到达；嵌套滚动和横纵手势不能互相抢夺。
- **NAV-06** 少量、空白、满载和极端长内容分别组织，不能只让默认数据看起来完整。
- **NAV-07** 同类区域保持共享节奏，不同任务允许适当密度差异；不因追求一致而把设置、图鉴与结果做成同一种内容模板。

## 弹层与临时信息原则

- **MOD-01** 弹层在合适时机承载明确任务，打开原因、当前内容和下一步容易理解，避免连续层叠造成迷失。
- **MOD-02** 面板比例由内容与可用空间决定，标题、装饰、正文、列表和操作分量协调，不用固定大容器承载所有提示。
- **MOD-03** 与底层通过遮罩、明暗或空间关系区分，必要的上下文仍可理解，模态与非模态行为符合外观暗示；对底层输入与计时的影响与实际任务规则一致。
- **MOD-04** 关闭、返回、取消和确认分别表达实际结果；无法安全关闭的阶段需要说明，而非静默移除出口。
- **MOD-05** 长正文与列表可以完整阅读，必要操作不被卷走或覆盖，显示与输入阻断的范围相互一致。
- **MOD-06** 错误提示靠近相关内容，并给可采取的下一步；短通知不承担复杂规则或必须记住的信息。
- **MOD-07** 普通功能、风险确认与阶段庆祝使用不同强度，同时共享游戏的视觉语言。

## 特效 动画与转场原则

- **MOT-01** 动效先解释变化，再强化感受；来源、过程与去向有可理解的关系，不能只有热闹而缺少含义。
- **MOT-02** 普通触达、有效操作、连续达成、阶段完成和重要奖励有递进层级，频繁事件轻量，稀少事件可以获得更强演出。
- **MOT-03** 预备、主要动作与收尾共同表达重量和性格，缓动、路径、弹性与形变应与对象材质协调，避免统一套用同一种弹跳。
- **MOT-04** 控制动作幅度、持续、频率与同时发生的数量；连续效果有主次，静止区域为阅读与观察保留空间。
- **MOT-05** 关键属性、目标和必要操作不被持续遮挡，粒子、高亮、漂浮文字和镜头运动不能互相叠加争抢注意。
- **MOT-06** 过渡表达空间或状态关系，避免无理由的方向变化、突然跳位和所有场景重复相同演出。
- **MOT-07** 需要保护的过渡防止冲突输入，无关装饰不制造额外等待；允许打断的动作在打断后有清楚稳定状态。
- **MOT-08** 动画表现与实际结果一致，未确认的事件不提前庆祝；恢复、刷新和重试不让玩家误以为再次获得奖励。
- **MOT-09** 闪烁、震屏、快速缩放和持续循环保持克制，需要时提供减少干扰的选择；较弱的表现仍保留关键含义。
- **MOT-10** 性能受限时优先保留操作响应、信息更新和必要反馈，不能为了装饰完整而让操作失去连续性。

## 音乐 音效与触觉反馈原则

- **SND-01** 声音与视觉共同表达对象、动作和情绪，同一事件各渠道的时机与强度协调。
- **SND-02** 重要状态不只通过声音或触觉传达，关闭这些渠道后仍能理解操作、警告与结果。
- **SND-03** 频繁操作的音效不持续累积或刺耳，多个事件同时出现时有主次，音乐不掩盖重要反馈。
- **SND-04** 音量与干扰程度有适合场景的控制，玩家选择在后续场景和恢复后保持可预期。
- **SND-05** 页面切换、暂停、中断与恢复维持听觉连续性，避免突兀重启、重复播放已结束事件或无意改变气氛。
- **SND-06** 触觉用于必要确认和关键事件，与视觉操作一致，不把每次轻触都变成强烈刺激。

## 引导 学习与重复游玩原则

- **LEARN-01** 引导结合实际操作，在玩家需要时逐步出现，先完成有意义的动作，再介绍复杂条件。
- **LEARN-02** 说明与相关对象相邻，文字、手势或示范在当前局面中容易对应，避免长说明与实际操作脱节。
- **LEARN-03** 让玩家理解动作与结果的因果关系，提供反馈与尝试空间，而不是只记住被指向的位置。
- **LEARN-04** 提示支持理解但不擅自替玩家作决定，是否显示答案与强制演示应符合游戏对探索的定位。
- **LEARN-05** 引导和辅助不遮挡关键内容，能处理误操作、取消与中断，恢复后仍知道下一步。
- **LEARN-06** 熟悉后的重复使用保持简短，必要说明有合理回看方式，避免每次重玩都付出相同学习成本。
- **LEARN-07** 界面便利性与玩法挑战分别判断；清除误读和误触，不意味着取消有意设置的策略或难度。

## 成果 奖励与失败表达原则

- **RES-01** 成功、失败、阶段完成和等待确认有各自含义，不用相同庆祝或模糊文案混淆结果。
- **RES-02** 成果说明帮助玩家理解表现与进展，不把所有数值、徽章和解锁同时放在相同视觉层级。
- **RES-03** 获得、解锁、拥有、累计、升级与可领取等概念清楚区分，视觉标记与实际事实一致。
- **RES-04** 奖励表现突出实际对象与变化，领取前后的状态明确，不因刷新或重复进入让同一成果看起来被再次发放。
- **RES-05** 演出与继续、重试、查看详情或离开的操作协调，重复游玩时不让庆祝成为固定负担。
- **RES-06** 失败解释对应实际条件，表达尊重玩家，避免惩罚性拖延；可行的下一步清楚，不承诺不存在的恢复机会。
- **RES-07** 排名或比较类内容明确范围、周期和计量口径，玩家自己的信息容易定位，加载失败不冒充无人参与。

## 道具 资源与商业化入口原则

仅在存在对应能力时适用，不据此要求增加广告、商店或付费能力。

- **ECON-01** 道具说明让玩家事先理解作用对象、适用条件、消耗和可能结果，外形隐喻不能与实际效果冲突。
- **ECON-02** 使用、获取、选择与确认分清，已有资源与潜在奖励不混在同一个数量中。
- **ECON-03** 余额不足、储备已满、次数限制、冷却或条件不符分别表达，不能全部表现为无解释灰按钮。
- **ECON-04** 付费、广告、分享或其他外部流程的入口如实说明成本，不借用免费操作的样式制造误解。
- **ECON-05** 取消与离开有清楚路径，避免视觉层级和控件位置诱导非预期的消耗或外跳。
- **ECON-06** 完成外部动作、回到游戏与实际获得奖励是不同阶段，表现与可验证结果一致。
- **ECON-07** 紧迫感、限时和稀有表现对应真实条件，不用无依据的倒计时或持续警告替代价值说明。

## 状态 异常与连续性原则

- **STATE-01** 正常、加载、空内容、不可用、失败和结果未知分别表达；没有内容不等于没有加载成功。
- **STATE-02** 等待说明当前在做什么，能够反映进度时如实反映，不能用虚假百分比或结果暗示制造确定性。
- **STATE-03** 处理中保留足够上下文与操作占位，玩家知道操作已接收，不必靠反复点击确认是否生效。
- **STATE-04** 失败提供可理解原因和适用的重试、返回或其他路径，不把未知结果直接宣告失败或成功。
- **STATE-05** 界面更新保持数据之间一致，避免文字、数量、图标和可操作状态属于不同阶段。
- **STATE-06** 切换页面、暂停、中断和恢复后保持可理解的进度与选择，不补执行已经失去语境的旧操作。
- **STATE-07** 首次加载、后续刷新和局部更新采用合适反馈，不必每次都重建整个画面或重播完整演出。

## 适配 可访问性与成品质感原则

- **ACC-01** 以实际观看尺度与目标输入方式判断，桌面放大图不能单独证明手机可读，近距离观察不能单独证明远距离可读。
- **ACC-02** 屏幕比例、方向、系统覆盖、文字缩放和长内容变化下维持主要关系，不以任意缩小全部内容应对空间不足。
- **ACC-03** 不以颜色、声音、微小纹理或单一手势作为关键含义的唯一渠道，提供适合实际平台的可理解替代。
- **ACC-04** 调整文字或减少动效等选择有对应效果，不破坏关键规则和必要反馈；是否改变挑战需单独明确。
- **ACC-05** 不把所有玩家都假设为视力正常、听音游玩、双手稳定且熟悉图标；阅读、精细操作和反应要求要与目标体验相符。
- **ACC-06** 图片、字体与图标在最终显示尺度清楚，裁切、压缩、采样、透明边缘和加载失败不造成含义丢失。
- **ACC-07** 资源未到达时保持合适的空间与可理解状态，替代资源和最终资源切换不产生无意跳动或重复文字。
- **ACC-08** 成品质感同时来自整体构图、细节一致与持续操作。没有裁切和对比问题只能证明相应质量，不能替代对趣味、个性和整体吸引力的判断。
