# Pretzel · 腿了个腿

版本：v2.0 · 更新：2026-11-02

本项目是微信动物卡牌求和消除小游戏。目前目录包含产品设计和视听素材，已建立客户端、后端与管理后台工程骨架，完整业务尚未实现。本文档集依据本次需求确认整理，不代表功能已经实现或平台能力已经验证。

## 文档权威与状态

- **已确认**：用户明确回答或接受的产品规则；以本文档集中的产品、玩法、道具文档为准。
- **实施建议**：为形成开发闭环提出的接口、存储、状态机和默认交互，不冒充已实现或逐项确认的需求。

- 产品规则优先于技术示例；接口和数据库应承接产品能力，不能以“未定义即不做”排除已确认需求。
- 变更先更新规则和决策记录，再同步契约、数据和验收；不得恢复旧版凑三张、复活或最高分模型。

当前指定技术栈：原生微信小程序客户端；React + Ant Design + TypeScript 管理端；Java 21 + Spring Boot + DDD + MySQL 后端。此前 Cocos、Node.js 和 Vue 方案已被替代。资源切图、动物动画、卡牌飞行与消除动效尚需整理制作。

## 工程启动

- `admin-web/`：React + Ant Design + TypeScript，执行 `npm ci`、`npm run dev`；`npm run build`构建。
- `backend/`：Java 21 + Spring Boot + DDD + MySQL，执行 `./mvnw test`；详情见backend/README.md。
- `miniprogram/`：原生微信小程序，开发者工具导入根目录，目前为三页导航骨架。
- `compose.yaml`：MySQL本地配置；复制.env.example为.env并替换密码，再运行`docker compose up -d`，不会自动部署。

重要平台差异：用户最新指定客户端为微信小程序，旧需求的“小游戏开放数据域好友榜”等能力仍需重新验证。本文档中的好友榜产品目标保留，但相关技术实现不能视为已确认可用于小程序。

英文工程名`pretzel`延续现有独立项目的食物命名风格，中文产品名为《腿了个腿》。
