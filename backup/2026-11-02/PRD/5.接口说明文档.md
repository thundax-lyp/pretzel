## 1. 通用约定

### 1.1 请求地址

| 端 | Base URL | 说明 |
|---|---|---|
| 小游戏端 | `wx.cloud.callContainer` 的 `path` 为 `/api/v1/**`，服务名 `game-api` | 走微信私有链路，无需自备域名、无需备案 |
| 管理端 | `https://admin.example.com/admin/**` | 独立自定义域名，IP 白名单，不走 callContainer |

### 1.2 鉴权

| 端 | 方式 |
|---|---|
| 小游戏端 | **无需传 token**。`callContainer` 请求头由微信注入 `X-WX-OPENID`（可信、不可伪造），服务端据此识别用户；服务端拒绝任何客户端自报 openid |
| 管理端 | 登录后获得 JWT，后续请求带 `Authorization: Bearer <token>`，有效期 8h；token 失效返回 2001 |

### 1.3 统一响应信封

```json
{ "code": 0, "msg": "ok", "data": {}, "trace_id": "a1b2c3d4" }
```

- `code`：0 为成功，非 0 见第 4 章
- `msg`：人类可读描述，前端可直接 toast
- `trace_id`：服务端链路 ID，用于日志排查，报障时请提供
- HTTP 状态码与 `code` 并存：业务错误通常 HTTP 200 + 非 0 code；鉴权失败用 401，限流用 429

### 1.4 分页约定（仅管理端）

请求：`page`（从 1 开始，默认 1）、`page_size`（默认 20，上限 100）

```json
{ "list": [], "total": 123, "page": 1, "page_size": 20 }
```

### 1.5 时间与字段类型

| 项 | 约定 |
|---|---|
| 服务端返回时间 | ISO 8601 带时区，如 `2026-10-31T21:00:00+08:00` |
| 客户端上报时间 | 毫秒时间戳（int64），如 `1730379600000`；仅作参考，统计以服务端时间为准 |
| 布尔 | `true/false`（存储层为 TINYINT(1)） |
| 比率 | 小数，如 `0.1234`（对应 DECIMAL(6,4)） |
| 金额 | MVP 无支付，不涉及 |
| ID 长度 | openid 最长 64；share_id 最长 64 |

### 1.6 限流与体积限制

| 项 | 限制 |
|---|---|
| 单接口通用频控 | 60 次/分钟/openid，超限返回 3001 |
| `/report/batch` | 单次 ≤ 20 条事件，body ≤ 16KB |
| 单条事件 `props` | ≤ 2KB |
| 管理端导出 | 单次 ≤ 50000 行 |

### 1.7 幂等说明（与表设计一致）

`event_log` 无事件级唯一键，因此 `/report/batch` **不做事件级去重**：客户端超时重试可能导致同一条事件重复落库（预期占比 < 0.5%）。统计口径统一使用"去重人数 / 去重 share_id"（见指标口径），可抵消重复影响。此为 MVP 明确取舍，不是缺陷。

## 2. 小游戏端接口

### 2.1 初始化会话

**用途**：小游戏启动时调用。完成用户建档（`user` upsert）、更新最近活跃时间、记录首次来源、下发全部运营配置。

| 项 | 内容 |
|---|---|
| 请求地址 | `POST /api/v1/session/init` |
| 请求方式 | POST |
| 鉴权 | 免 token（`X-WX-OPENID`） |
| 涉及表 | `user`（INSERT / UPDATE `last_seen_at`、`first_sid`）、`game_config`（SELECT 全量） |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| scene | string | 否 | 启动场景值（取自 `wx.getLaunchOptionsSync().scene`），≤32 字符 |
| sid | string | 否 | 来源分享 ID（首次进入时写入 `user.first_sid`） |
| from_share | boolean | 否 | 是否由分享卡片进入 |
| version | string | 否 | 客户端版本号，如 `1.0.3`，用于强更判断 |

**返回参数 `data`**

| 字段 | 类型 | 说明 |
|---|---|---|
| user.nickname | string/null | 昵称 |
| user.avatar_url | string/null | 头像地址 |
| user.created_at | string | 注册时间 |
| user.is_new | boolean | 是否本次新建（`created_at` 等于本次请求时间） |
| share_uid | string | 服务端下发的分享参数用 uid（即 openid，仅用于拼分享 path，非安全凭证） |
| config | object | 全部配置键值（`game_config.k → v`） |
| server_time | string | 服务端当前时间 |
| notice | string | 公告文本（`notice.text`，空串表示不展示） |

**请求示例（小游戏端）**

```js
// app.js
wx.cloud.init({ env: 'prod-xxxxxx' })

async function initSession({ scene, sid, fromShare }) {
  const res = await wx.cloud.callContainer({
    config: { env: 'prod-xxxxxx' },
    path: '/api/v1/session/init',
    method: 'POST',
    header: {
      'X-WX-SERVICE': 'game-api',
      'content-type': 'application/json'
    },
    data: {
      scene: String(scene || ''),
      sid: sid || '',
      from_share: !!fromShare,
      version: '1.0.0'
    }
  })
  if (res.data.code !== 0) throw new Error(res.data.msg)
  return res.data.data
}
```

**响应示例**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "user": {
      "nickname": "跳跳虎",
      "avatar_url": "https://thirdwx.qlogo.cn/xxx/132",
      "created_at": "2026-10-20T10:12:33+08:00",
      "is_new": false
    },
    "share_uid": "oX7bZ5aBcDeF1234567890",
    "config": {
      "difficulty.coef": 1.0,
      "revive.enabled": true,
      "revive.ad_limit": 1,
      "share.title": "我拿了 328 分，来挑战我",
      "notice.text": "",
      "version.min": "1.0.0"
    },
    "notice": "",
    "server_time": "2026-10-31T21:30:00+08:00"
  },
  "trace_id": "7f3c1a9e"
}
```

**错误**：1001（参数非法，如 sid 超长）、3001（频控）、5000（内部错误）

### 2.3 创建分享链路

**用途**：玩家点击分享时调用，生成 `share_id` 与分享 path，用于后续回流归因。

| 项 | 内容 |
|---|---|
| 请求地址 | `POST /api/v1/share/create` |
| 请求方式 | POST |
| 涉及表 | 无写入（`share_id` 在点击回流时才落 `share_attribution`） |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| channel | string | 否 | `session`（好友）/ `timeline`（朋友圈）/ `group`（群聊），默认 `session` |

**返回参数**

| 字段 | 类型 | 说明 |
|---|---|---|
| sid | string | 16~22 位随机分享 ID |
| path | string | 分享路径，含 `from=share&sid=xxx&uid=xxx` |
| title | string | 分享文案（取自 `game_config.share.title`） |

**请求示例**

```js
const { sid, path, title } = await createShare('session')
wx.shareAppMessage({
  title,
  imageUrl: 'share.png',
  query: `from=share&sid=${sid}&uid=${myOpenidForShare}` // 见下方兼容说明
})
```

> **实现说明（与表设计对应）**：`share_attribution.sharer_openid` 在回流时落库，服务端通过入参 `uid` 定位分享者。MVP 接受 `uid` 可被伪造（仅影响归因归属，不影响玩法与资金），加固阶段改为 HMAC 签名 `sid` 并在服务端反解（列入《加固方案》11.x 预留）。客户端所需的 `uid` 由 `/session/init` 的 `data.share_uid` 下发，客户端不再自行获取 openid。

**响应示例**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "sid": "s_9f2c7ab41d0e",
    "path": "pages/index/index?from=share&sid=s_9f2c7ab41d0e&uid=oX7bZ5aBcDeF1234567890",
    "title": "我拿了 328 分，来挑战我"
  },
  "trace_id": "c93aa017"
}
```

**错误**：1001（channel 非法）、3001（频控，防脚本刷 sid）

### 2.4 埋点批量上报

**用途**：批量上报玩法与传播事件，写入 `event_log`；其中 `share_open` 会额外写 `share_attribution`。

| 项 | 内容 |
|---|---|
| 请求地址 | `POST /api/v1/report/batch` |
| 请求方式 | POST |
| 涉及表 | `event_log`（批量 INSERT）、`share_attribution`（`share_open` 时 UPSERT）、`user`（`app_launch` 时 UPDATE `last_seen_at`） |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| events | array | 是 | 事件数组，1~20 条 |
| events[].event | string | 是 | 事件名，必须在 8 个白名单内（见 5.1） |
| events[].props | object | 否 | 事件参数，序列化后 ≤2KB |
| events[].ts | int64 | 是 | 客户端事件时间（毫秒时间戳） |
| events[].seq | int | 否 | 客户端自增序号，便于排查乱序 |

**事件级必填 props（服务端强校验）**

| 事件 | 必填 props |
|---|---|
| `game_over` | `score`(int≥0)、`duration_ms`(int>0) |
| `share_create` | `sid` |
| `share_open` | `sid`、`sharer_uid` |
| `revive_done` | `score`、`ad_result` |

**返回参数**

| 字段 | 类型 | 说明 |
|---|---|---|
| accepted | int | 成功接收条数 |
| rejected | array | 被拒条目 `{index, code, reason}`，客户端无需重试（避免无限循环） |

**请求示例（含攒批与失败重试）**

```js
const queue = []
let flushing = false

function track(event, props = {}) {
  queue.push({ event, props, ts: Date.now(), seq: queue.length })
  if (queue.length >= 10) flush()
}

async function flush() {
  if (flushing || !queue.length) return
  flushing = true
  const batch = queue.splice(0, 20)
  try {
    const res = await wx.cloud.callContainer({
      config: { env: 'prod-xxxxxx' },
      path: '/api/v1/report/batch',
      method: 'POST',
      header: { 'X-WX-SERVICE': 'game-api', 'content-type': 'application/json' },
      data: { events: batch }
    })
    if (res.data.code !== 0) throw new Error(res.data.msg)
  } catch (e) {
    queue.unshift(...batch) // 失败回填，下次重试（最多 3 次）
  } finally {
    flushing = false
  }
}

wx.onHide(() => flush())
```

**请求体示例**

```json
{
  "events": [
    { "event": "game_start", "props": { "mode": "classic" }, "ts": 1730379600000, "seq": 0 },
    { "event": "game_over", "props": { "score": 328, "duration_ms": 45000, "perfect_cnt": 12, "combo_max": 5 }, "ts": 1730379645000, "seq": 1 },
    { "event": "revive_done", "props": { "score": 328, "ad_result": "complete" }, "ts": 1730379648000, "seq": 2 }
  ]
}
```

**响应示例**

```json
{ "code": 0, "msg": "ok", "data": { "accepted": 3, "rejected": [] }, "trace_id": "e02b771c" }
```

**部分拒绝示例**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "accepted": 1,
    "rejected": [
      { "index": 1, "code": 1002, "reason": "unknown event: level_pass" },
      { "index": 2, "code": 1003, "reason": "props too large" }
    ]
  },
  "trace_id": "f10d3c88"
}
```

**错误**：1001（events 为空或超 20 条）、1002（事件名未登记）、1003（props 超限）、3001（频控）

### 2.5 拉取运营配置

**用途**：客户端启动或切前台时拉取最新配置（也可复用 `/session/init` 下发结果，此接口用于增量刷新）。

| 项 | 内容 |
|---|---|
| 请求地址 | `GET /api/v1/config` |
| 请求方式 | GET |
| 涉及表 | `game_config`（SELECT） |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keys | string | 否 | 逗号分隔的配置键；不传则返回全量（6 个种子键） |
| version | string | 否 | 客户端缓存的配置版本（ETag），一致时返回 304 语义（`code:0, data.changed:false`） |

**返回参数**

| 字段 | 类型 | 说明 |
|---|---|---|
| changed | boolean | 配置是否有变化 |
| version | string | 当前配置版本（所有配置 `updated_at` 的最大值哈希） |
| configs | object | 键值对 |
| server_time | string | 服务端时间 |

**请求示例**

```js
const res = await wx.cloud.callContainer({
  config: { env: 'prod-xxxxxx' },
  path: '/api/v1/config?keys=notice.text,revive.enabled&version=etag_1729',
  method: 'GET',
  header: { 'X-WX-SERVICE': 'game-api' }
})
```

**响应示例**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "changed": true,
    "version": "etag_1730",
    "configs": { "notice.text": "万圣节活动开启，复活次数 +1", "revive.enabled": true },
    "server_time": "2026-10-31T21:32:00+08:00"
  },
  "trace_id": "d41c9b05"
}
```

**错误**：3001（频控）

### 2.6 预留接口：成绩签名（**当前未启用**）

> 依据《加固方案》v0.1，MVP 阶段不实现。以下定义固化协议，便于后期无破坏升级。启用后签名写入关系链 KV，**不参与任何榜单计算**（好友榜仍由开放数据域提供）。

|---|---|

请求：无 body。返回：


#### 2.6.2 `POST /api/v1/match/score`

| 项 | 内容 |
|---|---|
| 用途 | 提交成绩，服务端校验后签发 Ed25519 签名 |
| 涉及表 | 无（不落榜、不落对局表） |

请求：

| 参数 | 类型 | 必填 | 说明 |

| duration_ms | int | 是 | 本局时长 |
| behavior_digest | string | 否 | 行为摘要（预留字段） |

```json

```

错误码：4001 token 无效 / 4002 时长校验失败 / 4003 分数超限 / 4090 行为摘要非法（详见第 4 章）

### 3.3 分析（P3 / P4）

#### `GET /admin/analytics/share?from=2026-10-01&to=2026-10-30`

响应 `data`：`{ trend: [...], top_sharers: [...], retention: {...} }`

- `trend[]`：`{dt, share_users, share_cnt, click_back, back_new_users, k_factor}`
- `top_sharers[]`：`{sharer_openid, share_cnt, click_back, back_new_users}`（`share_attribution` 聚合，Top 20）
- `retention`：`{d7_rate_new, d7_rate_old}`（新/老用户回流 7 日留存对比）

表操作：`share_attribution` 聚合 SELECT、`stats_daily` SELECT

#### `GET /admin/analytics/funnel?from=&to=`

响应 `data`：

```json
{
  "code": 0, "msg": "ok",
  "data": {
    "funnel": [
      { "step": "game_start", "users": 9860 },
      { "step": "game_over", "users": 9412 },
      { "step": "revive_show", "users": 5120 },
      { "step": "revive_done", "users": 4067 }
    ],
    "score_histogram": [ { "bucket": "0-99", "cnt": 8200 }, { "bucket": "100-199", "cnt": 12400 } ]
  },
  "trace_id": "4d5e6f"
}
```

表操作：`event_log` 按 `event` 分组 + `JSON_EXTRACT(props,'$.score')` 分桶

### 3.4 用户（P5）

#### `GET /admin/users?kw=&page=1&page_size=20`

`kw` 支持 openid 精确匹配、昵称模糊（前缀 `LIKE`，限 100 条并在响应 `hint` 提示）。

响应 `list[]`：`{openid, nickname, avatar_url, created_at, last_seen_at, first_sid}`（对应 `user` 表字段）

表操作：`user` SELECT

#### `GET /admin/users/{openid}`

响应 `data`：用户基础信息 + `stats: {game_cnt, best_score, share_cnt, back_new_users}`

表操作：`user` SELECT、`event_log` 聚合、`share_attribution` 聚合

#### `GET /admin/users/{openid}/events?event=&page=1&page_size=20`

响应 `list[]`：`{event, props, client_ts, server_ts}`（`event_log`）

表操作：`event_log` SELECT（`idx_openid_time`）

### 3.5 埋点明细与导出（P6）

#### `GET /admin/events?event=&from=&to=&openid=&page=1&page_size=20`

必填 `from`/`to`（最大跨度 31 天），否则 1001。

表操作：`event_log` SELECT（`idx_event_time`）

#### `GET /admin/events/export?event=&from=&to=`

响应：`text/csv` 流式下载，首行表头 `openid,event,props,client_ts,server_ts`；超过 50000 行直接 1001 并提示缩小范围。

表操作：`event_log` SELECT；`admin_audit_log` INSERT（action=`event.export`，detail 记录筛选条件）

### 3.6 配置与公告（P7 / P8）

#### `GET /admin/configs`

响应 `list[]`：`{k, v, remark, updated_by, updated_at}`（`game_config` 全量）

#### `PUT /admin/configs/{k}`

请求：`{ "v": 1.2, "remark": "万圣节难度下调" }`

服务端校验：键必须在白名单（6 个种子键 + 后续登记键）；`v` 需符合该键的 JSON schema（如 `revive.enabled` 必须 boolean，`version.min` 必须形如 `x.y.z`）。

响应：`{k, v, updated_at}`

表操作：`game_config` UPDATE（不存在则 INSERT）；`admin_audit_log` INSERT（detail 含 old/new）

权限：`version.min` 仅 super 可改。

#### `GET /admin/notice` / `PUT /admin/notice`

请求：`{ "text": "万圣节活动开启", "enabled": true }` → 映射为 `game_config` 的 `notice.text` 与 `notice.enabled` 两个键。

表操作：`game_config` SELECT/UPDATE；`admin_audit_log` INSERT

### 3.7 管理员（P9，仅 super）

| 接口 | 说明 | 表操作 |
|---|---|---|
| `GET /admin/admins?page=` | 账号列表（不含 password_hash） | `admin_user` SELECT |
| `POST /admin/admins` | 新建 `{username, password, display_name, role}` | `admin_user` INSERT；审计 |
| `PUT /admin/admins/{id}` | 改角色/显示名/启停（`status`） | `admin_user` UPDATE；审计 |
| `POST /admin/admins/{id}/reset-password` | 重置密码 `{new_password}` | `admin_user` UPDATE；审计 |

> 账号不物理删除，只置 `status=0`；停用后登录返回 2001。

### 3.8 审计（P10）

#### `GET /admin/audit?admin_id=&action=&from=&to=&page=1&page_size=20`

响应 `list[]`：`{admin_name, action, target, detail, ip, created_at}`

表操作：`admin_audit_log` SELECT（ops 角色强制 `admin_id = 自己`）

## 4. 错误码总表

| code | HTTP | 含义 | 客户端处理建议 |
|---|---|---|---|
| 0 | 200 | 成功 | — |
| 1001 | 400 | 参数缺失/非法 | 修参数，不重试 |
| 1002 | 400 | 事件名未登记 | 不重试，丢弃该条 |
| 1003 | 400 | props 超限 | 截断后下次重试 |
| 2001 | 401 | 未授权/账号密码错误 | 管理端跳登录；小游戏端不应出现 |
| 2002 | 403 | 权限不足（角色不够） | 提示无权限 |
| 2003 | 429 | 登录失败次数超限 | 提示 15 分钟后重试 |
| 3001 | 429 | 请求过于频繁 | 退避重试（指数退避，最多 3 次） |
| 4001 | 400 | match_token 无效（预留） | 重新开局 |
| 4002 | 400 | 时长校验失败（预留） | 不重试 |
| 4003 | 400 | 分数超限（预留） | 不重试 |
| 4090 | 400 | 行为摘要非法（预留） | 不重试 |
| 5000 | 500 | 服务内部错误 | 上报后重试 1 次 |
