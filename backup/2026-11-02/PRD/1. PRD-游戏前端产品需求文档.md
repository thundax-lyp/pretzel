## 1. 产品概述

### 1.1 一句话描述

层叠卡牌消除玩法小游戏：玩家从多层叠放的卡牌中选取卡牌放入卡槽，集齐题目中眼睛和对应退数量的动物卡牌即消除，
通关后解锁游戏中消除过的动物图鉴并且随机获得一只动物在自己首页的动物园广场上，并与微信好友比拼每周过关次数。
图鉴动物是永久的，过关获得的动物只能有一周显示在首页动物园广场，第二周周一随着关卡次数数据清空一起清空，

### 1.2 页面结构

```
启动加载页
   └─ 游戏首页
        ├─ 图鉴对话框
        ├─ 排行榜对话框
        ├─ 菜单对话框
        │    └─ 儿童隐私保护须知对话框
        └─ 游戏页
             ├─ 菜单对话框（含"放弃挑战"）
             │    └─ 放弃挑战二次确认对话框
             ├─ 道具获取对话框
             ├─ 胜利对话框
             └─ 失败对话框
```

### 1.3 全局弹窗规则

- 所有对话框均为模态弹窗：带半透明黑色遮罩，弹窗居中展示。
- 点击遮罩**不关闭**弹窗，必须通过弹窗内按钮操作。
- 同一时刻只允许存在一个弹窗；新弹窗打开前先关闭当前弹窗。
- 弹窗打开时暂停游戏计时与输入（游戏页内弹窗适用）。

## 2. 页面一：启动加载页

### 2.1 页面说明

游戏启动后的首个页面，用于资源预加载、品牌展示与合规信息展示。加载完成后自动进入游戏首页，用户无需任何操作。

### 2.2 界面元素

| 区域 | 元素 | 说明 |
|---|---|---|
| 背景 | 背景图 | 全屏展示，作为页面底图 |
| 背景层 | 游戏名称 | 展示在背景图上，位于页面上部视觉中心 |
| 背景层 | 四只小动物 | 分布于背景图上，静态或轻微动效 |
| 下方 | 加载进度条 | 横向进度条，实时反映资源加载进度（0%–100%） |
| 进度条上方 | 小乌龟动画 | 小乌龟向前行走的循环动画，随进度条前进 |
| 底部 | 合规信息区 | 自上而下依次展示：软件著作权信息、健康忠告文字、备案文字 |
| 右下角 | 年龄适应图标 | 固定展示，不可点击 |

### 2.3 交互逻辑

1. 页面进入即开始加载游戏资源（从服务器获取生成本次卡牌规则、图片加载到内存、声音和音效加入到内存），进度条同步更新。
2. 小乌龟行走动画与进度条联动：进度完成时乌龟走完进度条全程。
3. 进度达到 100% 后延迟约 0.5s，自动跳转至游戏首页；跳转过程无按钮确认。
4. 本页无任何可点击元素，不响应点击与滑动。

### 2.4 弹窗规则

- 本页无弹窗。
- 加载过程中断网：进度条停留，页面底部提示"网络异常，请检查网络后重试"，提供"重试"按钮，点击后重新加载。

## 3. 页面二：游戏首页

### 3.1 页面说明

游戏主入口页面，提供开始游戏、查看图鉴、查看排行榜、打开菜单四个入口 及一个分享按钮。

游戏主页面是一个动物园广场， 广场上是该周用户胜利过关后获得的动物集合（在广场上吃草，舔毛对应动效 参考首页视频.mp4），每周一0点清零，第二周重新获取

### 3.2 界面元素

| 区域 | 元素 | 类型 | 说明 |
|---|---|---|---|
| 左上角 | 菜单按钮 | 图标按钮 | 打开菜单对话框 |
| 底部正中 | "开始游戏"按钮 | 主按钮 | 进入游戏页 |
| 底部右侧 | "分享"按钮 | 次按钮 | 分享首页动物园快照到好友或者群 |
| 底部右侧 | "图鉴"按钮 | 次按钮 | 打开图鉴对话框 |
| 底部右侧 | "排行榜"按钮 | 次按钮 | 打开排行榜对话框 |



### 3.3 交互逻辑

1. 点击"开始游戏"→ 进入游戏页，开始本局挑战。
2. 点击"图鉴"→ 打开图鉴对话框（见 3.4）。
3. 点击"排行榜"→ 打开排行榜对话框（见 3.5）。
4. 点击"菜单"→ 打开菜单对话框（见 3.6）；此时菜单中**不显示**"放弃挑战"按钮。
5. 点击"分享"→ 分享首页快照（见 3.7）。

### 3.4 图鉴对话框

**页面说明**：展示玩家通过每周通关获得的动物，用于收集成就感展示。不展示未解锁动物灰度效果。列表最下方可以放置一行未解锁动物即可。

**界面元素**

| 元素 | 说明 |
|---|---|
| 动物图标 | 已解锁动物显示彩色图标 |
| 动物名称 | 已解锁动物显示名称|
| 动物简介 | 已解锁动物显示一句话简介 |
| 关闭按钮 | 右上角，点击关闭对话框 |

**交互逻辑**

1. 数据范围：仅展示**每周通关后获得**的动物，按解锁时间或图鉴编号排序。
2. 本周新解锁的动物图标带"NEW"角标，本周结束后角标消失。
3. 点击"关闭"或完成浏览后返回游戏首页，首页状态不变化。


### 3.5 排行榜对话框

**页面说明**：展示微信好友间的本周成绩排名。**仅好友榜，无全服榜**，数据来源于微信开放数据域。好友榜有2个tab页面，一个是“本周榜”、“历史榜”

**界面元素**

| 字段 | 说明 |
|---|---|
| 名次 | 第 1–3 名使用金银铜牌样式，其余为数字名次 |
| 头像 | 好友微信头像（开放数据域获取） |
| 昵称 | 好友微信昵称，超长省略号截断 |
| 本周过关次数 | 该好友本周累计通关次数，按数值降序排列 |
| 关闭按钮 | 右上角，点击关闭对话框 |

**交互逻辑**

1. 排序规则：按"本周过关次数"降序；次数相同按达成时间先后。
2. 自己的行背景高亮显示，且始终展示：若自己不在当前可见列表内，在列表底部固定显示自己的名次行。
3. 榜单统计周期为自然周（周一 00:00 至周日 24:00），每周一 00:00 清零重排。
4. 榜单区域可以上下滑动查看、点击"关闭"返回游戏首页。
5. 历史榜单是用的累计通关次数。

### 3.6 菜单对话框

**页面说明**：游戏设置与合规入口。在首页与游戏页均可打开，内容略有差异（见交互逻辑第 3 条）。

**界面元素**

| 元素 | 说明 |
|---|---|
| 音效滑动条 | 0–100 档滑动条，控制游戏音效音量 |
| 音乐滑动条 | 0–100 档滑动条，控制背景音乐音量 |
| "问题反馈"按钮 | 调用微信原生反馈组件（`wx.createFeedbackButton`） |
| "联系客服"按钮 | 调用微信原生客服组件（`wx.openCustomerServiceConversation`）|
| "放弃挑战"按钮 | **仅在游戏页打开菜单时显示**，首页打开时不显示 |
| 儿童隐私声明文字 | 菜单底部固定文案："儿童隐私保护声明及监护人须知"，可点击 |
| 关闭按钮 | 右上角，点击关闭对话框 |

**交互逻辑**

1. 音效/音乐滑动条：拖动实时生效并保存至本地缓存，下次启动沿用；拖到 0 即静音。
2. "问题反馈""联系客服"：唤起微信原生反馈/客服界面，操作完成后回到菜单对话框。
3. "放弃挑战"按钮的显示规则：
   - 从**游戏页**打开菜单 → 显示；
   - 从**首页**打开菜单 → 隐藏（此时无挑战可放弃）。
4. 点击底部"儿童隐私保护声明及监护人须知"文字 →先关闭菜单对话框，再弹出"儿童隐私保护须知"对话框；点击关闭后**返回原页面**。
5. 点击"关闭"返回打开菜单前的页面。

### 3.7 儿童隐私保护须知对话框

| 项目 | 规则 |
|---|---|
| 内容 | 展示儿童隐私保护声明及监护人须知全文，内容超出时区域内用户可以上下滑动 |
| 操作 | 仅提供"关闭"按钮 |
| 关闭行为 | 关闭后返回原页面 |

## 4. 页面三：游戏页

### 4.1 页面说明

核心玩法页面。玩家从多层叠放的卡牌区点击已露出可挪动的卡牌移入下方卡槽，卡槽内集齐 题目规则要求 张数动物卡牌即消除。卡牌全部消除即胜利；卡槽塞满且无可消除组合即失败。

### 4.2 界面元素

| 区域 | 元素 | 说明 |
|---|---|---|
| 右上角 | 菜单按钮 | 图标按钮，打开菜单对话框（含"放弃挑战"按钮） |
| 正上方 | 题目提示区 | 展示题目内容 |
| 中部 | 卡牌区 | 类"羊了个羊"的**十几层叠放卡牌**：每张卡牌显示一种动物图案；下层卡牌被上层遮挡，仅露出部分可点击 |
| 卡牌区下方 | 卡槽区 | 固定 7 格横向槽位；选中的卡牌按点击顺序依次移入；**卡槽区右上角显示数字**，含义见下 |
| 底部 | 道具按钮 ×3 | 自左向右："移除""撤回""洗牌"，每个按钮右下角显示当前持有数量角标 ，每局一个道具只能使用一次，使用完成即灰掉不能点击|

**卡槽区右上角数字**

- 含义：本局卡牌区中该批动物卡牌退的**总腿数**（即本局需消除的题目退总数）。
- 变化：随消除进度递减，卡牌区归零且卡槽清空即达成胜利条件。

### 4.3 核心玩法交互逻辑

1. **选牌入槽**：点击卡牌区中未被完全遮挡的可点卡牌，卡牌以飞行动画移入卡槽第一个空位。
2. **消除规则**：卡槽内集齐 题目中退的数量总和动物卡牌 → 多张卡牌播放消除动画并移出，腾出槽位。
3. **失败条件**：卡槽 7 格全部占满且不存在可消除组合  或者 用户选择卡牌腿的数量超过了题目数量 → 判定失败，弹出失败对话框（本游戏无复活）。
4. **胜利条件**：卡牌区与卡槽内所有卡牌全部消除 → 判定胜利，弹出胜利对话框。
5. **道具规则**：

| 道具 | 效果 |  
|---|---|
| 移除 | 将卡槽中所有卡牌移回卡牌区上方的暂存区，为卡槽腾出空间 | 
| 撤回 | 撤回最近一次移入卡槽的卡牌，放回原位 | 
| 洗牌 | 将卡牌区所有未消除卡牌位置随机重排 | 

5.1. 游戏默认2关详见游戏玩法说明文档
5.2. 道具第一关不能使用或者获取，
5.3. 道具获取与使用规则
初始状态：新开一局游戏时，道具图标右上角默认显示"+”，点击“+”弹出获取道具对话框；获取成功后返回游戏页面，“+”号变更为已持有的道具数量（"1"）。
获取途径：用户在以下三种场景中可随机获得道具（每场景限 1 次）：游戏失败对话框、游戏成功对话框、首页分享成功，所获道具可在下一局游戏中使用。
数量规则：随机获得的道具各不相同，不重复叠加（即同一道具不会叠加计数），当某道具已持有数量为 1 时，若再次随机获得该道具，则不再叠加，数量保持为 1。
（举例：用户在首页多次分享，每次分享成功随机可能只有一个道具获得1次（最大值不累计），这是游戏玩法设定不改变公平性，间接鼓励用户多分享，随机次数多了三个道具会集齐1次使用能力）
使用限制：一局游戏中，每个道具最多使用 2 次（本局外获得1次，本局内获得1次，使用完成变更为灰色）。

6. 游戏页点击右上角菜单 → 打开菜单对话框，此时**显示**菜单全部按钮包含"放弃挑战"按钮，游戏继续进行，计时不变。

### 4.4 弹窗规则

#### 4.4.1 胜利对话框

触发：本局所有卡牌消除完毕，将随机获得一只动物在首页展示。

| 元素 | 说明 |
|---|---|
| 好友排行榜 | 展示本周好友榜（名次、头像、昵称、本周过关次数），高亮自己的名次 |
| "回到首页"图标按钮 | 关闭本局，返回游戏首页 |
| "再次挑战"按钮 | 关闭本局并直接开始新的一局 |
| 分享按钮 | 分享当前排行榜战绩，默认文案由系统生成（如"我本周通关 N 次，快来超越我"） |

#### 4.4.2 失败对话框

触发：条件1卡槽占满且无消除可能，条件2 用户选择的腿数量大于眼睛数量。

| 元素 | 说明 |
|---|---|
| 好友排行榜 | 同胜利对话框 |
| "回到首页"按钮 | 关闭本局，返回游戏首页 |
| "继续挑战"按钮 | 无复活按钮，只能新开局继续挑战 |
| 分享按钮 | 分享文案固定为：**"这关太难了，我过不去"** |

#### 4.4.3 放弃挑战二次确认对话框

触发：游戏页菜单中点击"放弃挑战" ，先关闭菜单对话框，再弹出二次确认对话框。

| 项目 | 规则 |
|---|---|
| 文案 | "真的放弃挑战吗？" |
| 选择"是" | 放弃本局，关闭弹窗，返回游戏首页 |
| 选择"否" | 关闭确认框，返回游戏页，继续游戏（保持本局进度不变） |

#### 4.4.4 道具获取对话框

触发：点击持有数量为 0 的道具按钮，该道具图标右上角有+号。

| 元素 | 说明 |
|---|---|
| 道具说明 | 展示该道具的图标、名称与效果说明文案 |
| "分享获得"按钮 | 完成一次成功分享后发放 1 个该道具，对话框关闭，返回游戏页 |
| "看视频获得"按钮 | 完整观看一次激励视频后发放 1 个该道具，对话框关闭，返回游戏页 |
| "取消"按钮 | 关闭对话框，返回游戏页，不发放道具 |

通用规则：

1. 分享/看视频未完成（取消分享、中途关闭视频）不发放道具。
2. 道具发放后数量角标立即 +1，对话框自动关闭。
3. 单道具获取次数受每局上限约束（达上限后按钮置灰不能点击）。

## 5. 数据与埋点（关键项）


## 一、微信后台已有 → 无需自建

| 能力 | 微信已提供位置 |
|---|---|
| 启动/新增/活跃（DAU）、次日/3/7/30 日留存 | 数据助手-概况与留存 |
| 会话时长、访问页面（页面路径 PV） | 数据助手-访问与页面 |
| 分享次数/人数、分享回流、场景值来源分布 | 数据助手-分享与来源 |
| 激励视频曝光/点击/收入/eCPM、广告位维度数据 | 流量主后台 |
| 崩溃、JS 错误、启动耗时 | 运维中心-性能与错误 |

> 注意边界：微信只给**总量**，不给业务维度。例如“失败弹窗分享 vs 胜利炫耀分享”的转化差异、“好友榜单→开局”的攀比链路，微信报表看不到，这类仍需自定义事件（见下）。

## 二、调整现有埋点

| 事件 | 触发时机 | 上报参数 |
|---|---|---|
| 开局 | 进入游戏页 | 来源：`homepage` / `victory_retry` / `fail_continue` |
| 通关 | 胜利弹窗 | 本局用时、道具使用明细（移除/撤回/洗牌各次数）、是否使用复活、本关尝试次数 |
| 失败 | 失败弹窗 | 消除进度百分比、卡满时剩余动物种类数、本局道具使用数 |
| 道具使用 | 使用瞬间 | 道具类型、卡槽剩余空位、当局第几次使用 |
| 道具获取 | 发放成功 | 渠道（分享/视频）、触发道具、是否达每日上限被拦截 |

## 三、新增埋点

**A. 关卡难度与流失（羊了个羊核心）**

| 事件 | 触发时机 | 上报参数 |
|---|---|---|
| 关卡进度快照 | 每消除一组或每 30s | 已消除张数、剩余层数、卡槽占用数 |
| 中途退出 | 游戏中返回首页/切后台超时 | 退出时进度百分比、静置时长 |


**B. 业务维度的分享与广告**

| 事件 | 触发时机 | 上报参数 |
|---|---|---|
| 分享行为 | 分享发起/完成/取消 | 场景：胜利炫耀 / 失败求助 / 换道具 |
| 激励视频业务转化 | 视频完成后 | 场景：换道具 / 复活、对应道具或复活结果 |
| 分享回流归因 | 带参链接进入 | 分享者标识（scene 自定义参数）、回流后是否注册为新用户 |

**C. 收集与社交驱动**

| 事件 | 触发时机 | 上报参数 |
|---|---|---|
| 图鉴解锁 | 解锁瞬间 | 动物 ID、累计通关次数 |
| 榜单→开局链路 | 看榜单 30s 内开局 | 榜单类型（图鉴/好友榜）——验证攀比驱动，跳一跳验证过的最高价值链路 |

## 四、MVP 优先级

- **P0**：开局来源、通关/失败明细、复活曝光+转化、分享行为（业务场景）、激励视频业务转化
- **P1**：中途退出、关卡进度快照、分享回流归因
- **P2**：死局判定、榜单→开局链路、图鉴解锁明细
