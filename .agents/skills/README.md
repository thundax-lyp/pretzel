# 项目技能

- [PR Review](pretzel-pr-review/SKILL.md)：文档驱动的只读 PR 评审与 finding 收敛。
- [Codex Comment Fix](pretzel-codex-comment-fix/SKILL.md)：显式处理 Codex threads、summary findings 与修复回链。
- [关卡设计与验证](pretzel-level-design/SKILL.md)：真实布局导入、遮挡一致性、实验预算与自动证据报告。
- [Review Game UI](review-game-ui/SKILL.md)：用户主动指定文件名或路径，按检测点建队列并行检查，统一返回单项报告，汇总意见后逐截图给出修改清单。
