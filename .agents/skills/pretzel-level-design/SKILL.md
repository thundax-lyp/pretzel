# 关卡设计与验证

把真实关卡转成可复现的实验，交付本轮结论和证据。入口只负责路由与收口；详细契约在 references，所有执行能力在 scripts，使用 Node.js 22 原生 `.mjs`，不调用 Python 包装器。

## 按任务读取

- 开始设计或跨对话协作：读 [工作流与交付](references/workflow.md)，确定本轮范围、角色和终点。
- 设计半格错位、一盖二、一盖四、多盖一：读 [混合堆叠](references/mixed-stacks.md)，以完整牌为单位生成并做配对对照。
- 生成或导入布局：读 [输入与遮挡契约](references/layout-contract.md)，保留真实坐标、动物、题序与来源，核对点击模型。
- 运行、验证或解释实验：读 [预算与报告契约](references/experiment-contract.md)，明确预算，核验覆盖后解释结果。

从仓库根目录调用 `node .agents/skills/pretzel-level-design/scripts/level-design.mjs`；命令和参数见对应 reference。生成、导入、模拟、独立回放和报告均复用本 Skill 的模块，不在每次任务里重写算法。

## 必守边界

当前离线工具支持第二关 48 张、12 题、7 格卡槽。暂存牌按原位置及底牌身份免费复位，三种道具为移出、纠错、重排，重排保护复位锚点。需求、实验候选和真人验证分开；高度不能替代难度，参考解不能替代玩家策略测试。

先约定候选和预算，一轮只执行已列范围。完成计划、预算耗尽或出现规则错误均应收口；未运行案例不计失败，不自动追加实验、素材或改参数凑百分比。

视频使用和时长是显式假设下的模拟结果。零储备、满储备和策略分组，报告分母与缺口，不声称真人观看率、实际时长或生产验收已达标。

保留用户已有成果。协作只在用户授权范围内联系既有对话；无法读取对话时如实说明文件证据的边界。本 Skill 不授权新建对话、提交、推送、部署或接入真实广告。
