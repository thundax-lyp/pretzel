# 预算、证据与报告

## 单轮实验

`scripts/level-design.mjs run` 只比较给定输入，不生成额外候选、不自动重试调参。候选数量包括输入中的全部第二关记录；`--per-variant` 只控制每档取多少关评估，不能绕过导入候选上限。

| 参数             |                               默认 | 含义                                                    |
| ---------------- | ---------------------------------: | ------------------------------------------------------- |
| --max-candidates |                                 80 | 最多导入的关卡记录，超过就报错                          |
| --per-variant    |                                  2 | 按原输入顺序，每结构选取数量                            |
| --repeats        |                                  3 | 每关每策略、每场景的决策重复次数                        |
| --repeat-start   |                                 10 | 决策随机种子重复起点                                    |
| --max-runs       |                                100 | 所有结构、场景、策略合计运行上限                        |
| --max-seconds    |                                120 | 子进程硬时间上限，包含导入、参考解和模拟                |
| --scenarios      | no-tools,zero-reserve,full-reserve | 分别为无道具、零储备、每种各一次储备                    |
| --policies       |                            preview | 可指定 current、preview 或逗号分隔两者                  |
| --variants       |                                 空 | 全部结构；可用 4,6,7,8 选择已存在档位，缺少所选档位报错 |
| --ad-limit       |                                 10 | 三种道具共享视频奖励上限                                |
| --timing         |                       2.5,10,8,1.5 | 人工取牌或复位、每题思考、道具交互、自动重放的占位秒数  |

所需运行数等于选中关卡数 × 重复次数 × 场景数 × 策略数。运行上限不足仍会执行前缀、生成未完成报告；未测试案例保留为缺失。默认一次比较不是调参集/验证集的自动划分；现有材料只能称回归，不能冒称全新未见样本。

父进程用超时机制终止计算子进程，保留已经写完的逐行记录；报告生成和显式 verify 另计时间。退出码 0 表示计划完整结束，2 表示达到次数/时间预算，1 表示运行或输入错误。退出 2 不是请求自动扩大预算；先交付已有结果。

## 输出

- input.json：原始输入快照。
- config.json：范围、预算、时间假设、输入与代码 SHA-256。
- source/：当时执行的所有原生 `.mjs` 模块快照。
- journal.jsonl：导入数量、选中身份、布局、结构指标、每次完整动作和修复证书、停止原因。
- report.json：实际与计划覆盖、按结构/场景/策略分组的摘要和缺口。
- REPORT.md：自动生成的可读报告。
- worker.stderr：输入或运行异常的证据。

```sh
node .agents/skills/pretzel-level-design/scripts/level-design.mjs verify --output <实验目录>
node .agents/skills/pretzel-level-design/scripts/level-design.mjs report --output <实验目录>
```

verify 重算输入、选择、几何、参考路径、修复证书和分组统计。若工具版本已变化，使用实验目录的 `source/level-design.mjs` 执行 verify，以免把不同实现混成同一次证据。report 在验证后重建可读摘要，不重跑实验。

## 结论口径

所有比例的分母是对应分组已完成的尝试数。无视频通关可能使用储备；“最多三次通关”包含零次。预算中止的运行没有结果，不能计作失败；部分组也不能用于宣布整体目标达标。

自动报告把 75%—85% 作为零储备视频使用的观察带，只提示是否落入区间，不把它当成硬合格线或真人广告率。看过视频案例中一至三次内的通关比例、十次仍失败、无可证修复和搜索触界一并保留；满储备另列，不假定人群库存比例。

默认时间模型是人工取牌或复位各 2.5 秒、每题思考 10 秒、道具交互 8 秒、自动重放每题 1.5 秒。它们是占位假设，广告与后台停留另计。真实 4—6 分钟与观看意愿需要另行真人验证。

停止条件在开始前固定：完成计划、达到预算或出现规则错误。不要为达到某个百分比，在同一轮不停改输入、替换失败样本或扩大实验。需要下一轮时先说明要检验的假设和新预算。

随机算法固定为 `sha256-xorshift32-v1`，种子、算法版本和当前源代码随配置保存。动作记录区分取牌 take、免费复位 restore 与 remove、correct、repack 三种道具。独立回放分别校验复位条件、原位保护、自动纠错范围、库存及视频计数。真人难度比较必须使用同一规则版本和固定输入。
