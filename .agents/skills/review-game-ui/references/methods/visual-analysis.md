# 视觉观察与方案比较方法

执行范围由检测点节与 QUEUE.json 的当前条目确定。只执行该点选中的方法，逐方法记录实际步骤、证据与限制，写回同一条目的结果；不自行新增或扩大检测点。

## M-01

**方法**：整屏体验观察

- **适用输入**：保留完整构图和原始比例的画面，当前任务、游戏类型、情绪与风格目标；动态体验另需完整过程。物理显示尺度未知时仍可观察静态关系，不能据此确认目标尺度可读。
- **步骤**：先不放大局部，记录第一感受、最先看到的内容与想执行的动作；再指出支持或妨碍目标的主体、容器、环境关系；记录值得保留的个性与主要失衡。
- **产出**：保留项、失衡位置、对任务或情绪的影响，以及待定位原因。
- **限制**：方向未知时区分观察与目标判断；不能只用“好看”“廉价”等词给出无关系依据的结论。
- **本点执行与产出**：先看包含本点对象的完整画面，记录主题与任务关系、保留项及失衡位置。

## M-02

**方法**：视觉顺序与比例分析

- **适用输入**：整屏及其主要区域、当前任务与必要行动。
- **步骤**：标出首要焦点及后续观看路径；比较主体、承托、文字与操作的体量、明暗和留白；必要时用缩略或灰度辅助识别竞争，再回正常颜色与尺度复看。
- **产出**：焦点顺序、竞争对象、比例或密度关系及其影响；测量值需要时由 M-05 提供。
- **限制**：不套用固定面积比例，也不把灰度效果当成最终配色结论。
- **本点执行与产出**：标出本点对象在整屏中的视觉重量、观看路径和与相邻区域的比例关系。

## M-03

**方法**：同类与跨页面并置

- **适用输入**：可比较的对象、状态或页面，明确版本、尺度及任务差异。
- **步骤**：选择同类与必要边界样本，以相近显示尺度并置；逐项比较字体、色彩、轮廓、信息位置和状态含义；区分共享规则与为任务服务的有意差异。
- **产出**：样本范围、一致或冲突关系、差异是否合理的依据。
- **限制**：不把不同年代截图混作当前状态，不因追求统一而消除任务需要的差别。
- **本点执行与产出**：并置本点涉及的同类对象或已标识截图，逐一说明一致与有意差异。

## M-06

**方法**：配色与形体语言对照

- **适用输入**：完整画面、相邻对象及当前情绪和风格方向。
- **步骤**：区分大色块与强调、主体与材质；比较色相、明暗、饱和度及轮廓、厚度、光照、细节密度的相互关系；说明这些关系如何支持或打断目标气质。
- **产出**：具体相邻关系、协调或冲突位置、任务与风格依据。
- **限制**：孤立色板和素材技术不能替代完整效果；配色协调不能替代文字可读或语义正确。
- **本点执行与产出**：对照本点对象及相邻内容的色彩、轮廓、材质与风格目标，说明协调或冲突关系。

## M-24

**方法**：装饰减弱与方案对照

- **适用输入**：已有同状态对照稿，或授权范围内可安全预览、恢复的表现变体。
- **步骤**：保持内容与尺度相同，仅比较待判断的装饰或表现强度；观察重心、阅读和氛围变化；指出减少干扰的收益及损失的主题记忆点，再回完整方案判断。
- **产出**：对照条件、改动变量、收益与代价。
- **限制**：总表仅在存在对照材料时要求本方法。无材料可提出对照建议，不自行把删装饰当作更高级，也不为审查发布或改动正式素材。
- **本点执行与产出**：使用已有同状态装饰对照，说明本点重心、氛围与主题记忆的收益和代价。

## M-26

**方法**：文字职责与美术表达分析

- **适用输入**：完整画面、具体文字对象、可见文本及其职责；已有同状态变体可辅助比较，不以变体为开始静态审美判断的前提。
- **步骤**：先独立定位品牌、情绪标题、固定主要行动与功能/数值/正文，说明固定性及展示体量；逐对象判断是否需要定制展示字。再检查整体字形轮廓、笔画转折、字间节奏、适用的厚度/材质/光影和趣味细节；将文字与相邻角色、场景比较，说明自身的个性、记忆与精细程度是否足够。最后回完整画面检查主次，给出本对象的保留、调整或待验方向；适用维度未采用效果时说明是否有意且成立，不机械要求全部装饰。
- **产出**：文字角色与选型、逐维度观察、所在位置、与相邻美术的关系、判断理由及具体改法；有变体时补同条件对照。
- **限制**：不从截图推定实际字体家族、资源格式或是否使用系统默认字体。静态可观察的审美表达可以独立作出结论，不能借缺少真机输入回避；实际尺度辨认、字形加载/替代、按钮状态和动态按对应方法另验。定制字不限位图，未经对照不声称新方案已改善。
- **本点执行与产出**：对当前文字对象作出职责选型及美术表达判断，明确字形、轮廓/节奏和适用质感与角色场景之间的关系。
