# 操作、空间与恢复方法

执行范围由检测点节与 QUEUE.json 的当前条目确定。只执行该点选中的方法，逐方法记录实际步骤、证据与限制，写回同一条目的结果；不自行新增或扩大检测点。

## M-11

**方法**：操作路径与命中实测

- **适用输入**：可操作原型或运行环境，约定输入方式和任务。
- **步骤**：从真实入口完成目标动作；检查中心与边缘命中、相邻区域、返回路径及当前支持的滚动、拖动或定向导航；记录触发、取消、被遮挡或错误去向的具体轨迹。
- **产出**：设备、动作位置或轨迹、预期与实际行为、可复现路径。
- **限制**：截图不能证明命中，原型不能证明生产消费或权威结果；不同输入方式只查约定支持范围。
- **本点执行与产出**：在目标输入环境实际完成本点相关操作，记录动作、命中、取消及真实去向。

## M-12

**方法**：连续操作与重复输入

- **适用输入**：可安全重复的实际流程或明确范围的测试环境，操作前状态与有效约定。
- **步骤**：连续使用正常高频操作；在处理中、切换或动画期间施加约定范围内的重复输入；比较反馈累积、入口状态和最终结果，并对照前后事实。
- **产出**：操作序列、节奏、发生冲突的时刻及最终状态；缺少事实时注明视觉观察边界。
- **限制**：不为审核制造真实重复购买或发奖。发现一次问题不自动增加无界压力或执行预算。
- **本点执行与产出**：在本点允许重复的范围内连续操作，记录反馈累积、重复输入和前后结果。

## M-15

**方法**：返回、中断与恢复检查

- **适用输入**：当前页面和进度、允许的切页、返回、暂停、失焦、断连或恢复条件。
- **步骤**：记录中断前选择、页码、滚动、资源及操作阶段；在明确时点退出或中断并恢复；对照当前约定检查位置、进度、旧输入、动画和操作锁。
- **产出**：中断点、恢复路径、前后状态及残留旧动作证据。
- **限制**：不能以一次普通返回代替处理中恢复，也不自行清空真实数据来制造初始状态。
- **本点执行与产出**：记录本点的中断前状态，返回或恢复后对照选择、进度、旧输入与操作锁。

## M-23

**方法**：空间归属与遮挡检查

- **适用输入**：同屏对象、分组、标记、层序及必要交互关系，动态关系另需连续过程。
- **步骤**：标出每条属性、标记或说明属于谁；检查相邻、叠放、弹层和输入遮挡；把涉及多对象的冲突记录为关系，并核对视觉与实际可操作关系。
- **产出**：参与对象、归属或层序、冲突区域及其后果。
- **限制**：独立素材和节点顺序不能替代组合画面；涉及真实命中或变化时，检查本点方法组是否已包含 M-11 或 M-13；尚未列入的必要方法作为缺口返回 parent，由 parent 更新队列，不将空间观察当作实际操作或动态证据。
- **本点执行与产出**：标出本点对象、标记和覆盖层的归属及层序，说明具体冲突位置与影响。
