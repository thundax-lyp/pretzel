# 内容、状态与事实方法

执行范围由检测点节与 QUEUE.json 的当前条目确定。只执行该点选中的方法，逐方法记录实际步骤、证据与限制，写回同一条目的结果；不自行新增或扩大检测点。

## M-09

**方法**：内容边界矩阵检查

- **适用输入**：当前支持的数据类型、数量与长度范围，真实或明确标识的代表数据。
- **步骤**：列出适用的正常、少量、空、满页、末页、长名称、大数值或约定语言样本；逐个展示并检查布局和可达性；记录每个样本的结果，例外分行。
- **产出**：样本矩阵、输入值或来源、截断、拥挤、跳位和不可达证据。
- **限制**：未配置出的样本是未覆盖；模拟数据只证明模拟内容，不证明真实数量、排序或资源余额。
- **本点执行与产出**：为本点列出真实支持的内容边界，逐状态检查；不同截图的结果分别留底。

## M-10

**方法**：状态矩阵检查

- **适用输入**：实际存在的可用、按下、选中、禁用、锁定、加载、空、失败、未知等状态及其触发条件。
- **步骤**：按当前能力列出状态；逐个触发或查看已确认材料，比较文案、图形和操作；检查必要切换是否同步，条件不同则分开记录。
- **产出**：状态、触发依据、显示和行为结果、未取得的状态材料。
- **限制**：源码有分支不等于状态已运行；空内容、失败和未知结果不能互相替代。
- **本点执行与产出**：为本点列出实际存在的状态及触发条件，检查表达与必要切换，不以默认态替代其他态。

## M-14

**方法**：语义与权威事实核对

- **适用输入**：当前有效玩法、接口或资源规则，以及同一事件可核验的权威状态和界面表达。
- **步骤**：写明待核对事实及权威来源；对齐事件、对象和阶段，比较文字、数量、标记、可操作状态和结果；异常或未知阶段保留其不确定含义。
- **产出**：规则依据、对应事件与事实、显示差异和可观察后果。
- **限制**：源码、模拟响应和画面宣告均不能单独证明真实发奖或消费；无法取得事实时只报告可核对部分和缺口。
- **本点执行与产出**：将本点界面表达与同一对象、事件和阶段的有效约定及权威事实对齐。

## M-25

**方法**：文案与信息图形解释

- **适用输入**：文案、图标、标记或进度图形，以及对象、任务与阶段上下文。
- **步骤**：逐项解释它表达的用途、对象、条件、成本、当前阶段和下一步；检查歧义隐喻、术语混用、省略与归属；需要事实时补 M-14，需要玩家理解证据时补 M-20。
- **产出**：当前可解释含义、歧义或缺失位置及与任务的关系。
- **限制**：审核者给出合理解释只是语义评估，不能宣告玩家已理解；“确定”“继续”等词应结合具体去向判断。
- **本点执行与产出**：结合本点对象和阶段解释文案或图形的用途、条件、成本及下一步，定位歧义。
