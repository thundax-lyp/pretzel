# 辨认、对比与测量方法

执行范围由检测点节与 QUEUE.json 的当前条目确定。只执行该点选中的方法，逐方法记录实际步骤、证据与限制，写回同一条目的结果；不自行新增或扩大检测点。

## M-04

**方法**：实际尺度辨认与阅读

- **适用输入**：目标显示尺度和观看距离明确的画面或设备，待辨认对象及要读取的信息。
- **步骤**：在正常尺度执行辨认、比较或阅读任务；记录混淆、漏读、停顿及需要放大的位置；必要时放大定位原因后回原尺度重查。
- **产出**：环境与尺度依据、实际读辨任务、具体困难及位置。
- **限制**：只有放大稿时不能确认实际可读。需要“操”类证据的阅读点必须实际完成目标尺度下的阅读并记录显示及观看条件，无需人为增加点击；比例已知的静态图本身不能证明已经完成这一步。审核者能读出不证明目标玩家均理解，理解问题使用 M-20。
- **本点执行与产出**：在已确认的目标显示尺度与观看条件下完成本点所需的阅读或辨认，记录具体困难。

## M-05

**方法**：几何与排版测量

- **适用输入**：具有比例依据的截图、设计或运行布局；命中范围需要实际交互数据。
- **步骤**：先确认逻辑单位、物理像素与缩放关系；按有效轮廓记录对象体量、字号、间距、行距、基线或命中边界；对照项目已有标准，并回完整画面判断比例效果。
- **产出**：测量对象、单位、方式、实测值、约定值和差异。
- **限制**：视觉外框不等于命中范围。无比例依据时只记录相对关系；无已定标准时不编造数字通过线。
- **本点执行与产出**：围绕本点判据选定几何对象，记录有效轮廓、尺寸、间距或基线的单位、依据和实测值。

## M-07

**方法**：最终合成与对比检查

- **适用输入**：文字或对象最终合成画面，相关背景、透明叠加及项目对比标准。
- **步骤**：在对象真实显示位置检查轮廓和笔画；覆盖最亮、最复杂或相关动态背景阶段；需要量化时按当前有效标准记录合成后的取样区域、方式与值，再复看实际辨认效果。
- **产出**：发生干扰的区域或时刻、合成条件及可复查的对比证据。
- **限制**：不能只比较未叠加的色值，也不能以单一背景的测量值代表整个变化过程。没有动态材料时保留该部分缺口。
- **本点执行与产出**：检查本点所在的最终合成区域，记录笔画、轮廓、透明叠加及相关背景条件下的辨认依据。

## M-08

**方法**：单一感知线索去依赖

- **适用输入**：原始表达及实际支持的冗余或替代渠道。
- **步骤**：每次只移除一个依赖，如忽略色相、关闭声音或使用已有替代入口；检查关键属性、警告与操作结果是否仍可获得；记录剩余线索及不能完成的任务。
- **产出**：被移除的线索、所用替代渠道和信息缺口。
- **限制**：不要求产品同时支持所有设备或输入方式。灰度等辅助分析仅支持对应缺口判断，不等于完成全部可访问性验证。
- **本点执行与产出**：去掉一个关键感知线索后，记录本点含义能否从已有替代渠道获得。
