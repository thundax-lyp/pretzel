# 动态、声音与触觉方法

执行范围由检测点节与 QUEUE.json 的当前条目确定。只执行该点选中的方法，逐方法记录实际步骤、证据与限制，写回同一条目的结果；不自行新增或扩大检测点。

## M-13

**方法**：完整动态过程观察

- **适用输入**：包括触发前、开始、主要过程、收尾和结束后的连续录屏或现场运行。
- **步骤**：先正常播放看节奏，再逐段定位响应、来源去向、遮挡和结束状态；记录关键时间或帧及同时出现的内容；重复事件与中断场景有材料时分别观察。
- **产出**：时间定位、阶段描述、持续干扰与状态落点。
- **限制**：剪辑或抽帧未展示的部分不推断通过；只有计时图形不能证明服务端时间或结果事实。
- **本点执行与产出**：观察本点事件的完整动态过程，定位触发、变化、遮挡、收尾和结束状态。

## M-18

**方法**：声音与混音实听

- **适用输入**：实际有声过程、声音控制及代表并发事件，记录播放环境。
- **步骤**：听正常、频繁和并发事件；对照视觉时机和音乐层次；检查已有音量或关闭选项，以及切页或恢复后的听觉连续性。
- **产出**：事件与时间、掩盖或累积现象、控制结果。
- **限制**：静音视频和音效文件列表不能证明实际混音；听感判断注明环境，不推断未测设备。
- **本点执行与产出**：实际听取本点事件的正常和并发播放，记录与画面的时机、混音及控制结果。

## M-19

**方法**：触觉实测

- **适用输入**：实际支持触觉的目标设备、事件及已有控制方式。
- **步骤**：触发普通与关键事件，比较时机、强度和持续；核对触觉是否对应实际操作与结果；已有关闭或减弱选项时检查其效果。
- **产出**：设备、事件、感知差异及控制结果。
- **限制**：代码调用或录屏无法证明实际振感；无触觉能力时按范围记录不适用。
- **本点执行与产出**：在目标设备实际感知本点触觉，记录事件、强度、时机及已有开关效果。
