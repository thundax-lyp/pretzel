# 显示与资源方法

执行范围由检测点节与 QUEUE.json 的当前条目确定。只执行该点选中的方法，逐方法记录实际步骤、证据与限制，写回同一条目的结果；不自行新增或扩大检测点。

## M-16

**方法**：显示适配矩阵检查

- **适用输入**：约定支持的屏幕尺寸、比例、方向、系统覆盖及文字缩放条件。
- **步骤**：建立最小代表矩阵；在每个条件下检查主体关系、边缘、文字和操作可达性；记录重排、浏览或缩小方式是否仍支持任务，必要时回到实际输入检查。
- **产出**：显示条件、裁切或覆盖位置、布局变化及未覆盖配置。
- **限制**：不新增未承诺的横屏、语言或设备支持；模拟显示与真机观察分别标识。
- **本点执行与产出**：在约定的目标显示矩阵中检查本点，逐一记录边缘、重排与可达性。

## M-17

**方法**：资源、字体与替代呈现检查

- **适用输入**：最终资源及其实际缩放、裁切、压缩、字形、加载与替代过程。
- **步骤**：比较原始资源和最终合成，检查有效轮廓、边缘、采样与字形；在已有能力范围内查看未到达、替代和失败状态；检查切换后的比例、位置及重复内容。
- **产出**：资源或字符定位、显示条件、变形缺字或替代问题及前后材料。
- **限制**：加载过程未取得时不声明已验证；不把源图清楚当成最终尺度清楚。
- **本点执行与产出**：检查本点最终资源、字体和替代呈现，记录缩放、裁切、加载与缺字边界。
