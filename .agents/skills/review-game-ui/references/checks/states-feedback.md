# 状态与反馈检测点

- 检测阶段：分类
- 对象范围：加载、正常、失败、未知与恢复阶段的界面。

按队列的 point_ref 直接定位本文件中的检测点节。每节保留自己的判据和方法组，队列、负责人及单项报告仍按检测点划分。

单项边界与方法选择见[队列规则](../review-queue.md)，证据边界见[审核流程](../review-workflow.md#证据代号与适用条件)，结果按[统一返回契约](../result-contract.md)回收。

## STATE-01.1

- 原则编号：STATE-01

**提问**：当前状态表达准确吗？

**通过判据**：正常、加载、空、不可用、失败与结果未知有清楚区别。

**最低证据**：图+实。
