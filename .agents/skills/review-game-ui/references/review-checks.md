# 游戏 UI 与 UE 检测点列表

本列表用于生成检测队列，直接链接每个检测点在分类 reference 中的独立节。各点保留自己的判据、最低证据和方法组；同类点共享文件与对象范围，执行及返回规则由公共协议维护。先按 [审核流程](review-workflow.md) 整体观察与拆分对象，再按 [队列规则](review-queue.md) 为截图、对象和状态选点建项。

每个队列项仅包含一个检测点，并由一个负责人完成该点选中的全部方法。可以把多个独立项批量分配给 subagent，但每项分别返回 [统一结果](result-contract.md)，再由 parent 汇总并 [展开逐截图修改单](report-output.md)。共享方法可复用证据，不能用方法摘要替代检测点单项报告。

分类文件以检测点编号为二级标题，例如 `## TXT-02.1` 对应锚点 `#txt-021`。提问或说明调整时保留编号标题，队列与报告即可持续直接定位该点。
